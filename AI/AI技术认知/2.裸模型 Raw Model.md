# 裸模型 Raw Model

## 概述

+ 概述

  ```
   输入                              输出
  Token List ----> Raw Model ----> 概率分布（下一个字的概率分布）
                      ⬆
                      |
                      | GPU 运算（并行运算，浮点数 相加 不满足 加法的结合律，所以存在误差 ）
                      |
           训练/微调   ⬇
          --------> 权重矩阵
            语料
  ```

## Token List 数字列表

+ 数字列表

  ```
  // 自然语言换算成数字的结果（分词）
  [2,3,4,5,8]

  一个中文字平均  ≈ 1.5 token
  一个英文单词平均 ≈ 1.3 token
  ```

+ 上下文窗口 Context Window

  ```js
  // k 表示 千（1000）
  128k = 12.8 万 token

  128000 / 1.5 ≈ 85333 个中文
  ```

## 概率分布

+ 下一个词的输出概率分布

  ```js
  // 输入
  [177519] // 你好

  // 输出
  {
    15: 0.7,  // 70% 的概率 下一次词是 “，”
    288: 0.2, // 20% 的概率 下一次词是 “吗”
    ...
  }
  ```
