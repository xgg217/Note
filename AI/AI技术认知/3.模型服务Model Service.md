## 步骤2 Model Service API

+ 前处理

  + 身份/权限 认知
  + 提示词注入（系统提示词、用户提示词）
  + Tokenization 分词 token化

+ 自回归

  + 调用 裸模型

    ```js
    // 伪代码
    const input = [...]; // token 化的结果

    const output = []; // 输出

    while(1) {
      const prob = raw_model(input); // 根据输入计算下一个token的概率分布

      // prob 数据结构
      {
        25874: 0.7, // 70% 的概率
        54634: 0.2,
        ...
      }

      // options包含 temperature、top_k
      const token = probToken(prob, options);

      // 是否结束
      if(isOver(token)) {
        break;
      }

      output.push(token);
      input.push(token);
    }
    ```

+ 后处理

  + 把token变成自然语言
  + 合规性检查
  + ...
