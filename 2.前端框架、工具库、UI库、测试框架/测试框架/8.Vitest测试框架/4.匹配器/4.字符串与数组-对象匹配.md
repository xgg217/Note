# 字符串与 数组/对象 匹配

## toMatch 字符串是否匹配正则表达式

+ 可以检查字符串是否和某一个正则表达式能够匹配上

  ```js
  test("字符串相关匹配器",()=>{
    expect("this is a test").toMatch(/test/);
    expect("this is a test").not.toMatch(/abc/);
  })
  ```

## toContain 数组/字符串中是否包含某元素/子串

+ 数组 / 字符串 中是否包含某元素/子串
+ toContain 进行的是全等比较，也就是严格比较

  ```js
  const shoppingList = [
    "diapers",
    "kleenex",
    "trash bags",
    "paper towels",
    "milk",
  ];

  test("数组相关匹配器", () => {
    expect(shoppingList).toContain("milk");

    // toContain 进行的是全等比较，也就是严格比较
    expect([1, 2, 3]).not.toContain("1");

    expect([{ name: "张三" }, { name: "李四" }]).toContain({ name: "张三" }); // false 内存地址不相等
    expect([{ name: "张三" }, { name: "李四" }]).not.toContain({ name: "张三" }); // true

    // 也可以用到集合（set）里面
    expect(new Set(shoppingList)).toContain("milk");
  });
  ```

  ```js
  // toContain 还可以用来检测一个字符串是否是另一个字符串的子串
  expect("this is a test").toContain("test");
  ```

## toContainEqual

+ 数组中是否包含匹配某个对象的元素

  ```js
  expect([{a:1}]).toContainEqual({a:1})
  ```

## toHaveLength

+ 检查数组/字符串的长度

  ```js
  expect('abc').toHaveLength(3)
  ```

## toMatchObject

+ 对象是否匹配子集（包含某些属性）

  ```js
  expect({a:1, b:2}).toMatchObject({a:1})
  ```

## toHaveProperty(keyPath, value?)

+ 对于检查单个属性，尤其是嵌套属性，toHaveProperty更易读取。你通过一个点分路径，并可选地传递一个期望值

  ```js
  test('object has property', () => {
    const user = {
      name: 'Alice',
      address: { city: 'Paris', zip: '75001' }
    }

    expect(user).toHaveProperty('name')
    expect(user).toHaveProperty('name', 'Alice')
    expect(user).toHaveProperty('address.city', 'Paris')
    expect(user).toHaveProperty('address.zip')
  })
  ```
