# 布尔值相关匹配器

## 概述

+ 一般来讲运行结果得到的是一个布尔值，使用布尔值相关匹配器的时候一般是无需传参的

  ```js
  test("布尔值相关匹配器",()=>{
    const n = null;
    expect(n).toBeFalsy();
    expect(n).not.toBeTruthy();

    const a = 0;
    expect(a).toBeFalsy();
    expect(a).not.toBeTruthy();
  })
  ```

## toBeTruthy 判断值是否为真

+ 判断值是否为真（`true` 或能转为 `true`）

  ```js
  expect(1).toBeTruthy()
  ```

## toBeFalsy 判断值是否为假

+ 判断值是否为假（`false` 、 `0` 、 `''` 、 `null` 、 `undefined`）

  ```js
  expect(0).toBeFalsy()
  ```

## toBeNull 严格匹配 null

+ 严格匹配 `null`

  ```js
  expect(null).toBeNull()
  ```

## toBeUndefined 严格匹配 undefined

+ 严格匹配 `undefined`

  ```js
  expect(undefined).toBeUndefined()
  ```

## toBeDefined 匹配非 undefined 的值

+ 匹配非 `undefined` 的值

  ```js
  expect(1).toBeDefined()
  ```
