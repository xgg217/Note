# 常见匹配器

## toBe 基本类型比较

+ toBe 匹配器会检查该值是否恰好使用 `Object.is`
+ 这对原始值如数字、字符串和布尔值非常有效
+ 如果是对象，则检测内存地址是否一致

  ```js
  import { expect, test } from 'vitest'

  test('two plus two is four', () => {
    expect(2 + 2).toBe(4)
  })
  ```

## toEqual 对象深度比较

+ 递归比较对象的属性值（深拷贝相等，适合对象/数组）

  ```js
  test("深度比较对象",()=>{
    const stu = {name : "张三", score : {html : 100, css : 90}};

    expect(stu).not.toBe({name : "张三", score : {html : 100, css : 90}});

    // 使用 toEqual 来进行深度比较
    // toEqual 会递归比较对象的所有属性
    expect(stu).toEqual({name : "张三", score : {html : 100, css : 90}});
  })
  ```

## toStrictEqual

+ 比 `toEqual` 更严格，会检查 `undefined` 属性和类型

  ```js
  expect({a:1, b: undefined}).toStrictEqual({a:1}) // 失败
  ```
