# 版本管理

## pyenv

+ 建议使用 pyenv 来管理多个 Python 版本

## mac安装 pyenv

+ mac 建议使用 HomeBrew 安装 pyenv

## window 安装 pyenv

+ 以管理员身份打开 powershell

  ```bash
  # 解决权限问题
  Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

  # 运行安装命令
  Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/pyenv-win/pyenv-win/master/pyenv-win/install-pyenv-win.ps1" -OutFile "./install-pyenv-win.ps1"; &"./install-pyenv-win.ps1"

  # 测试
  pyenv --version
  ```

## window 配置镜像源

+ 步骤1:右键 --> 此电脑 --> 属性 --> 高级系统设置 --> 环境变量
+ 步骤2: 在 用户变量（只影响当前用户） 或 系统变量（所有用户） 点新建

  + 变量名： `PYTHON_BUILD_MIRROR_URL`
  + 变量值： 填任意一个镜像源

    ```
    # 推荐使用
    https://mirrors.huaweicloud.com/python/

    https://mirrors.aliyun.com/python
    ```

+ 步骤3 命令行执行 `pyenv update` 来刷新这个缓存

## pyenv 使用

+ 使用

  ```bash
  # 查看所有可安装的 Python 版本
  pyenv install --list

  # 利用管道命令搜索
  pyenv install --list | grep "^ 3.14"

  # 安装特定版本
  pyenv install 3.14.1

  # 卸载特定版本
  pyenv uninstall 3.14.1

  # 查看已安装的版本
  pyenv versions

  # 查看正在使用的版本
  pyenv version
  ```

+ 切换版本

  ```bash
  # 切换全局版本
  pyenv global 3.14.1

  # 切换本地版本（只作用于当前文件夹）
  pyenv local 3.14.1

  # 切换当前终端版本（临时生效）
  pyenv shell 3.14.1
  ```
