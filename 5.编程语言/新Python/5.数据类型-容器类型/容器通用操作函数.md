# 容器通用操作函数

## 容器通用操作函数

+ 以下函数适用于所有容器类型（`list`、`tuple`、`dict`、`set`、`str`）：

  ```py
  # len() —— 获取元素个数
  len([1, 2, 3])       # 3
  len((1, 2, 3))       # 3
  len({"a": 1, "b": 2}) # 2（键值对数量）
  len("hello")         # 5

  # max() / min() —— 最大/最小值
  max([3, 1, 4, 1, 5])  # 5
  min((3, 1, 4))        # 1
  max("hello")          # 'o'（按字符编码）

  # sum() —— 求和（元素必须是数字）
  sum([1, 2, 3, 4])     # 10
  sum((1, 2, 3))        # 6

  # sorted() —— 排序，返回新列表
  sorted([3, 1, 2])           # [1, 2, 3]
  sorted((3, 1, 2))           # [1, 2, 3] —— 返回列表
  sorted("cba")               # ['a', 'b', 'c']
  sorted([3, 1, 2], reverse=True)  # [3, 2, 1]

  # reversed() —— 反转，返回迭代器
  list(reversed([1, 2, 3]))   # [3, 2, 1]
  list(reversed("abc"))       # ['c', 'b', 'a']
  ```
