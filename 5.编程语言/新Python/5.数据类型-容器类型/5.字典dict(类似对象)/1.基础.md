# 基础

## 概述

+ 字典是Python的**键值对**存储结构，通过键快速查找值

## 重要注意事项

+ 键必须是不可变类型

  ```python
  # 键必须是不可变类型（hashable）
  valid = {
      "string": 1,      # str ✓
      42: 2,            # int ✓
      (1, 2): 3,        # tuple ✓
      # [1, 2]: 4,     # list ✗ 不可哈希！
  }

  # 字典的键是唯一的，重复赋值会覆盖
  person = {"name": "Alice", "name": "Bob"}
  print(person)  # {'name': 'Bob'}
  ```

+ `value` 可以是任意的数据，并且可以重复
