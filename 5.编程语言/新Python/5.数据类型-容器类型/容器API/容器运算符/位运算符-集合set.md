# 位运算符

## 位运算符

+ 对于**集合（set）**，位运算符有特殊的集合运算含义：

  ```python
  s1 = {1, 2, 3}
  s2 = {2, 3, 4}

  # & 交集（两个集合都有的元素）
  s1 & s2       # {2, 3}

  # | 并集（两个集合所有的元素，去重）
  s1 | s2       # {1, 2, 3, 4}

  # - 差集（在 s1 中但不在 s2 中的元素）
  s1 - s2       # {1}
  s2 - s1       # {4}

  # ^ 对称差集（只在其中一个集合中的元素）
  s1 ^ s2       # {1, 4}

  # ~ 不适用于集合，用于整数的按位取反
  ```

+ 对比：位运算 vs 集合方法

  ```python
  s1 = {1, 2, 3}
  s2 = {2, 3, 4}

  # 运算符写法
  s1 & s2        # {2, 3}
  s1 | s2        # {1, 2, 3, 4}
  s1 - s2        # {1}
  s1 ^ s2        # {1, 4}

  # 方法写法（等价）
  s1.intersection(s2)      # {2, 3}
  s1.union(s2)             # {1, 2, 3, 4}
  s1.difference(s2)        # {1}
  s1.symmetric_difference(s2)  # {1, 4}
  ```

+ **注意**：位运算符只能用于**集合（set）**，不能用于 `list`、`tuple`、`dict` 等其他容器类型
