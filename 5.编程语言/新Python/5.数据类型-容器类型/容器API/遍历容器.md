# 遍历容器

## 基本 for 循环

+ for 循环

  ```python
  # 遍历列表
  for item in [1, 2, 3]:
      print(item)

  # 遍历元组
  for char in ("a", "b", "c"):
      print(char)

  # 遍历字符串
  for ch in "hello":
      print(ch)  # h, e, l, l, o
  ```

## 遍历字典

+ 遍历字典

  ```python
  person = {"name": "Alice", "age": 25, "city": "北京"}

  # 遍历键（默认）
  for key in person:
      print(key)

  # 遍历键值对
  for key, value in person.items():
      print(key, value)

  # 仅遍历值
  for value in person.values():
      print(value)

  # 仅遍历键（显式）
  for key in person.keys():
      print(key)
  ```

## 遍历集合

+ 遍历集合

  ```py
  s = {1, 2, 3}
  for item in s:
      print(item)
  # 注意：集合是无序的，遍历顺序不固定
  ```

## `enumerate()` 函数

+ 遍历容器时，如果需要同时获取索引和值，使用 `enumerate()`

  ```py
  # 基本用法
  fruits = ["苹果", "香蕉", "橙子"]
  for index, fruit in enumerate(fruits):
      print(f"{index}: {fruit}")
  # 0: 苹果
  # 1: 香蕉
  # 2: 橙子

  # 指定起始索引
  for i, v in enumerate(fruits, start=1):
      print(f"{i}. {v}")
  # 1. 苹果
  # 2. 香蕉
  # 3. 橙子
  ```

## `zip()` 函数

+ 并行遍历多个容器，元素按位置一一配对：

  ```python
  names = ["Alice", "Bob", "Charlie"]
  ages = [25, 30, 35]
  cities = ["北京", "上海", "广州"]

  for name, age, city in zip(names, ages, cities):
      print(f"{name} 今年 {age} 岁，住在 {city}")

  # zip 以最短容器为准
  short = [1, 2]
  long = ["a", "b", "c"]
  for x, y in zip(short, long):
      print(x, y)
  # 只输出两组：1 a 和 2 b
  ```
