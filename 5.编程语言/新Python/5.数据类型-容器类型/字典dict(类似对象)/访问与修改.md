# 访问

## 访问

+ 访问

  ```py
  person = {"name": "Alice", "age": 25}

  # 访问
  print(person["name"])       # Alice
  # print(person["gender"])   # KeyError!
  ```

## 安全访问

+ 安全访问

  ```py
  person = {"name": "Alice", "age": 25}

  # 安全访问
  print(person.get("gender"))         # None（不报错）
  print(person.get("gender", "未知"))  # 未知（提供默认值）
  ```
