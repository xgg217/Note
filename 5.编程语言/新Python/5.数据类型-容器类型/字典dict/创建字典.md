# 创建字典

## 创建字典

+ 创建字典

  ```python
  # 字面量创建
  person = {
      "name": "Alice",
      "age": 25,
      "city": "北京"
  }
  empty = {}      # 空字典

  # 通过dict()函数创建
  person = dict(name="Alice", age=25, city="北京")
  person = dict([("name", "Alice"), ("age", 25)])

  # 从键序列创建，值默认为None或指定
  d = dict.fromkeys(["a", "b", "c"], 0)
  # {'a': 0, 'b': 0, 'c': 0}
  ```
