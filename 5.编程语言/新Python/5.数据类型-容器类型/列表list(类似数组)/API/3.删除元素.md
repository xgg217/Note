# 删除元素

## 删除元素

+ 删除元素

  ```py
  nums = [1, 2, 3]

  nums.remove(0)        # [1, 2, 3, 4, 5, 6] 删除第一个匹配值
  popped = nums.pop()   # 6, nums变为[1, 2, 3, 4, 5]  删除并返回末尾
  popped = nums.pop(0)  # 1, nums变为[2, 3, 4, 5]    删除并返回指定位置
  del nums[0]           # [3, 4, 5]  删除指定位置
  nums.clear()          # []  清空列表
  ```
