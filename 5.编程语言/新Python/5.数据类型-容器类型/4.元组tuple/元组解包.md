# 元组解包

## 元组解包

+ 元组解包

  ```py
  coord = (3, 4)
  x, y = coord
  print(x, y)      # 3 4
  ```

## 扩展解包

+  扩展解包（Python 3+）

  ```py
  first, *rest = (1, 2, 3, 4)
  print(first)     # 1
  print(rest)      # [2, 3, 4]
  ```

  ```py
  *rest, last = (1, 2, 3, 4)
  print(rest)      # [1, 2, 3]
  print(last)      # 4
  ```
