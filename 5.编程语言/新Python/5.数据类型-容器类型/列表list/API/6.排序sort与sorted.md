# 排序

## 排序 sort

+ 升序

  ```py
  nums = [3, 1, 4, 1, 5]
  nums.sort()              # [1, 1, 3, 4, 5]  原地排序
  ```

+ 降序

  ```py
  nums = [3, 1, 4, 1, 5]
  nums.sort(reverse=True)  # [5, 4, 3, 1, 1]  降序
  ```

## 排序但不修改原列表 sorted

+ sorted

  ```py
  nums = [3, 1, 4]
  sorted_nums = sorted(nums)  # [1, 3, 4], nums不变

  print(nums) # [3, 1, 4]
  print(sorted_nums) # [1, 3, 4]
  ```
