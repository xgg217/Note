# Lambda表达式

## 概述

+ Lambda表达式用于创建**匿名函数**——即没有名称的临时函数
+ 当你需要一个简单函数且只用一次时，lambda能让代码更简洁

## 语法

+ 语法

  ```python
  lambda 参数1, 参数2, ... : 表达式
  ```

+ 对比

  ```python
  # 普通函数
  def add(x, y):
      return x + y

  # 等价的lambda
  add_lambda = lambda x, y: x + y

  print(add(2, 3))         # 5
  print(add_lambda(2, 3))  # 5
  ```

## 特点

+ 只能包含**一个表达式**，不能写多条语句
+ 表达式的计算结果**自动返回**
+ 通常不命名，即用即走
