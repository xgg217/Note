# 返回值

## 使用 return

+ 函数通过 `return` 返回结果：

  ```python
  def square(x):
      return x ** 2

  result = square(4)
  print(result)  # 16
  ```

## 多返回值

+ Python 函数可以**同时返回多个值**（实际是返回元组）：

  ```python
  def min_max(numbers):
      return min(numbers), max(numbers)

  minimum, maximum = min_max([3, 1, 4, 1, 5])
  print(minimum)  # 1
  print(maximum)  # 5

  # 本质上返回的是元组
  result = min_max([3, 1, 4])
  print(result)       # (1, 4)
  print(type(result)) # <class 'tuple'>
  ```

## 没有 return

+ 如果函数没有 `return`，默认返回 `None`：

  ```python
  def say_hello():
      print("Hello")

  result = say_hello()  # Hello
  print(result)         # None
  ```
