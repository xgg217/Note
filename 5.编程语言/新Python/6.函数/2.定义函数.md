# 定义函数

## 语法

+ 语法

  ```py
  def 函数名 ([参数列表]):
    '''注释'''
    函数体/若干语句
    return <返回值列表>
  ```

  ```py
  # 定义
  def xgg ():
      print('调用')

  # 调用
  xgg()
  ```

## 定义函数

+ 使用 `def` 关键字定义函数：

  ```python
  # 定义一个简单函数
  def greet():
      print("Hello, World!")

  # 调用函数
  greet()  # Hello, World!
  ```
