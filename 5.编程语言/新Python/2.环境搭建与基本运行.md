# 环境搭建

## 安装包

+ Python 安装包中包含以下核心组件

  + 解释器：默认为 CPython
  + 包管理器：pip
  + 标准库：os、sys、urllib、pathlib
  + 交互式终端： PEPL

## 发行版

+ Python 有很多发行版，不同的发行版又有很多版本

  + 官方 Python(CPython)：C语言原生实现，Python 标准参考版本，带 GIL 生态最全，日常开发默认首选
  + ActivePython：商业公司打包的 CPython 发行版，企业级稳定适配，预装常用依赖，偏商用场景
  + Anaconda：面向数据科学的全家桶 CPython，内置海量数据分析，AI 库，体积大，适合数据分析一站式环境

## 测试运行

+ 步骤1 新建 `helli.py` 文件， 文件内容为 `print("Hello World!")`
+ 步骤2 在当前目录打开命令行，运行 `python hello.py`

## IDE

+ Pycharm: python 专属 IDE，开箱即用，专为 Python 设计，官方内置了 Python 开发的诸多功能
+ VSCode: 通用代码编辑器，装插件才支持 Python

### VSCod 插件

+ Python: 语法高亮、代码提示词、运行调试、虚拟环境识别，最核心插件

  + 安装 `Python` 的同时会自动安装 `Python Debugger` `Python Environments`

+ Code Runner: 右键一键运行 Python 代码，不用敲命令，新手超好用

  + VSCode 配置 `settings.json`

    ```json
    "code-runner.executorMap": {
      ...
      "python": ""
    }
    ```

+ Blak Formatter: 自动格式化代码，统一代码风格，不用手动排版
