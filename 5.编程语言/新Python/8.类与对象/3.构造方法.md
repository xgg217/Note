# 构造方法

## 构造方法 `__init__`

+ `__init__` 是类的构造方法，在创建对象时自动调用，用于初始化对象的属性：

  ```python
  class Dog:
      def __init__(this, name, age):
          this.name = name
          this.age = age

  # 创建对象时传入参数
  my_dog = Dog("Buddy", 3)
  print(my_dog.name)  # Buddy
  print(my_dog.age)   # 3
  ```

+ **注意：** `self` 代表对象本身，必须是第一个参数，但调用时不需要传
