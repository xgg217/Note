# 三元运算符（条件表达式）

## 概述

+ Python 的三元运算符（条件表达式）是一种简洁的 `if-else` 写法，用于在一行中根据条件选择不同的值

## 语法

+ 语法

  ```py
  结果 = 真值 if 条件 else 假值
  ```

  ```py
  score = 85

  # 传统写法
  if score >= 60:
      result = "及格"
  else:
      result = "不及格"

  # 三元运算符（更简洁）
  result = "及格" if score >= 60 else "不及格"
  print(result)  # 及格

  # 嵌套三元运算符（不推荐过度嵌套）
  age = 25
  category = "青年" if age < 40 else ("中年" if age < 60 else "老年")
  ```

**注意：** 三元运算符适合简单的条件判断，复杂的逻辑应使用传统的 `if-else` 结构以保持代码可读性
