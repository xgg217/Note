# 海象运算符 :=

## 概述

+ Python 3.8 引入的**赋值表达式**，可以在表达式中同时进行赋值和求值

  ```python
  # 传统写法：先赋值，再判断
  line = input("输入: ")
  while line != "quit":
      print(f"你输入了: {line}")
      line = input("输入: ")

  # 使用海象运算符：赋值和判断合二为一
  while (line := input("输入: ")) != "quit":
      print(f"你输入了: {line}")
  ```

**注意：** 海象运算符是 Python 3.8 的新特性，老版本不支持
