# 算数运算符

## 加法运算符 +

+ `+`

+ 不同类型相加

  + `int + int` 数值相加
  + `float + float` 数值相加
  + `str + str` 字符串拼接
  + bool `True=1, False=0`
  + `NoneType` 不支持

## 减法运算符 -

+ `-`

+ 不同类型相加

  + `int - int` 数值相减
  + `float - float` 数值相减
  + `str - str` 不支持
  + bool `True=1, False=0`
  + `NoneType` 不支持

## 乘法运算符 *

+ `*`

+ 不同类型相加

  + `int * int` 数值相乘
  + `float * float` 数值相乘
  + `str * str` 字符串重复
  + bool `True=1, False=0`
  + `NoneType` 不支持

## 除法运算符 /

+ `/`

+ 不同类型相加

  + `int / int` 返回 float
  + `float / float` 返回 float
  + `str / str` 不支持
  + bool `True=1, False=0`
  + `NoneType` 不支持

## 整除 //

+ `//`

+ 不同类型相加

  + `int // int` 整数除法
  + `float // float` 整数除法
  + `str // str` 不支持
  + bool `True=1, False=0`
  + `NoneType` 不支持

## 模(取余) %

+ `%`

+ 不同类型相加

  + `int % int` 取余数
  + `float % float` 取余数
  + `str % str` 不支持
  + bool `True=1, False=0`
  + `NoneType` 不支持

## 幂运算 **

+ `**`

+ 不同类型相加

  + `int ** int` 幂运算
  + `float ** float` 幂运算
  + `str ** str` 不支持
  + bool `True=1, False=0`
  + `NoneType` 不支持
