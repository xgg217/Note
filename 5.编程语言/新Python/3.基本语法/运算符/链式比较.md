# 链式比较

## 概述

+ Python 支持**链式比较**，可以像数学公式一样连续写比较运算符：

  ```py
  x = 5

  # 传统写法（其他语言）
  print(x > 1 and x < 10)   # True

  # Python 链式比较（更简洁）
  print(1 < x < 10)         # True
  print(1 < x <= 5)         # True
  print(5 <= x < 10)        # True
  print(1 < x < 3)          # False

  # 甚至可以更复杂
  print(1 < x < 10 < 100)   # True
  ```

# 等价规则

+ `a < b < c` 等价于 `a < b and b < c`，但**只计算一次** `b`
