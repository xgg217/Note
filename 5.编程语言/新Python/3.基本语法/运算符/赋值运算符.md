# 赋值运算符

## 概述

+ 概述

  | 运算符 | 示例      | 等价于       | 适用类型        |
  | ------ | --------- | ------------ | --------------- |
  | `=`    | `a = 5`   | -            | 所有类型        |
  | `+=`   | `a += 3`  | `a = a + 3`  | int, float, str |
  | `-=`   | `a -= 3`  | `a = a - 3`  | int, float      |
  | `*=`   | `a *= 3`  | `a = a * 3`  | int, float, str |
  | `/=`   | `a /= 3`  | `a = a / 3`  | int, float      |
  | `//=`  | `a //= 3` | `a = a // 3` | int, float      |
  | `%=`   | `a %= 3`  | `a = a % 3`  | int, float      |
  | `**=`  | `a **= 3` | `a = a ** 3` | int, float      |

  ```py
  # int
  a = 10
  a += 5    # a = 15
  a -= 3    # a = 12
  a *= 2    # a = 24
  a /= 4    # a = 6.0 (注意：/= 结果变为float)
  ```

  ```py
  # str
  s = "Hello"
  s += " World"  # s = "Hello World"
  s *= 2         # s = "Hello WorldHello World"
  ```
