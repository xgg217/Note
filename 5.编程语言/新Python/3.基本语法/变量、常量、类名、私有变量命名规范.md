# 命名规范

## 变量名

+ 小写字母，下划线分割

  ```py
  name

  user_name
  ```

## 常量

+ 全大写字母，多个单词使用下划线隔开

  ```py
  PI

  MAX_SIZE
  ```

## 函数名

+ 全小写字母，多个单词之间用下划线隔开

  ```py
  phone

  my_name
  ```

## 类名

+ 首个字母大写，采用大驼峰命名规则

  ```py
  UserInfo

  DateModel
  ```

## 私有变量

+ 以下划线开头

  ```py
  _internal

  __private
  ```

## 模块和包名

+ 全小写字母，尽量简单
+ 若多个单词之间用下划线

  ```py
  math
  os
  ```
