# 变量类型转换

## int 字符串 --> 整数

+ int

  ```py
  age_str = "25"
  age_int = int(age_str)
  print(age_int) # 25
  ```

## str 整数 --> 字符串

+ str

  ```py
  num = 100
  num_str = str(num) # "100"
  ```

## float 整数 --> 浮点数

+ float

  ```py
  x = 5
  x_float = float(x)
  ```

## int 浮点数 --> 整数（截断小数）

+ int

  ```py
  x = 3.9
  x_int = float(x) # 3 (不是四舍五入)
  ```

## bool  --> 布尔

+ bool

  ```py
  bool(0) # False
  bool(1) # True
  bool("") # False
  ```
