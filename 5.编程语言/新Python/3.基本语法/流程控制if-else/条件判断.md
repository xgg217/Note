# 条件判断

## 概述

+ 概述

  | 语法         | 说明                                    |
  | ------------ | --------------------------------------- |
  | `if 条件:`   | 条件为True时执行                        |
  | `elif 条件:` | 前一个条件为False且当前条件为True时执行 |
  | `else:`      | 前面所有条件都为False时执行             |

  ```py
  # 基本if-else
  age = 18
  if age >= 18:
      print("成年人")
  else:
      print("未成年人")

  # if-elif-else
  score = 85
  if score >= 90:
      grade = "A"
  elif score >= 80:
      grade = "B"
  elif score >= 60:
      grade = "C"
  else:
      grade = "D"
  print(f"成绩等级: {grade}")
  ```

## 注意

+ Python使用缩进（通常为4个空格）表示代码块，不使用花括号
