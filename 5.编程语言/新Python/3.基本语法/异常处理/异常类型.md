# 异常类型

## 异常类型

+ Python 内置异常形成层次结构，捕获父类异常可以捕获其所有子类：

  ```
  BaseException
  ├── SystemExit          # sys.exit() 引发
  ├── KeyboardInterrupt   # Ctrl+C 引发
  └── Exception           # 常规异常的基类
        ├── ArithmeticError
        │    └── ZeroDivisionError
        ├── LookupError
        │    ├── IndexError
        │    └── KeyError
        ├── TypeError
        ├── ValueError
        │    └── UnicodeError
        └── ...
  ```

  ```python
  # 捕获 Exception 可以捕获几乎所有常规异常
  try:
      # 可能引发各种异常的操作
      pass
  except Exception as e:
      print(f"发生错误: {e}")

  # 但不推荐捕获过于宽泛的异常，应尽量精确
  ```
