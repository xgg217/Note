# 作用域速查

## 作用域速查

+ 作用域速查

  ```python
  # 1. 简单函数
  name = "global"

  def func():
      name = "local"    # 局部变量，不影响全局
      print(name)       # local

  func()
  print(name)           # global

  # 2. 嵌套函数

  def outer():
      name = "outer"

      def inner():
          name = "inner"   # 自己的局部变量
          print(name)      # inner

      inner()
      print(name)          # outer

  outer()

  # 3. 使用 nonlocal
  def outer():
      name = "outer"

      def inner():
          nonlocal name
          name = "modified"  # 修改外层变量

      inner()
      print(name)            # modified

  outer()
  ```
