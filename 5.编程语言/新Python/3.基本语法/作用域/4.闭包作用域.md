# 闭包作用域

## 访问外层函数变量

+ 嵌套函数中，内层函数可以访问外层函数的变量：

  ```python
  def outer():
      x = "outer"       # 外层函数的局部变量

      def inner():
          print(x)      # 访问外层变量

      inner()

  outer()  # outer
  ```

## 修改外层变量

+ 内层函数不能直接修改外层变量：

  ```python
  def counter():
      count = 0

      def increment():
          count += 1    # UnboundLocalError！

      increment()

  # counter()
  ```

+ 使用 `nonlocal` 关键字：

  ```python
  def make_counter():
      count = 0
      
      def increment():
          nonlocal count   # 声明使用外层变量
          count += 1
          return count
      
      return increment

  counter = make_counter()
  print(counter())  # 1
  print(counter())  # 2
  print(counter())  # 3
  ```
