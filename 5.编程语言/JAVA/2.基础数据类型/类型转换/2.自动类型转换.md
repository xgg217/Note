# 自动类型转换

## 概述

+ 自动类型转换：当 java 程序在进行赋值 或 运算 时，精度小的类型自动转换成精度大的数据类型

  ```java
  byte -> short -> int -> long -> float -> double
  ```

  ```java
  char -> int -> long -> float -> double
  ```

## 规则

+ 规则1 当有多种数据类型混合运算时，系统先自动将所有数据转换成容量最大的那种数据类型，然后再进行计算

  ```java
  int n1 = 10;

  // 错误
  float d1 = n1 + 1.1; //  1.1是 double 类型，计算结果也是 double 类型

  // 解决方式1
  double d1 = n1 + 1.1;
  // 解决方式2
  float d1 = n1 + 1.1f;
  ```

+ 规则2 当我们把精度（容量）大的数据类型赋值给精度小的数据类型时，会报错，反之就会进行自动类型转换
+ 规则3 `byte` `short` 和 `char` 之间不会相互自动转换
+ 规则4 `byte` `short` `char` 他们三者可以九三，在计算时
+ 规则5 `boolean` 不参与转换
+ 规则6 自动提示原则：表达式结果的类型自动提升为操作数中最大的类型

## 示例

+ 示例

  ```java
  int a = 'c';
  System.out.println(a); // 99 char -> int

  double d = 80;
  System.out.println(d); // 80.0 int -> double
  ```

## 规则

+ 如果任一操作数是 double 类型，其他操作数将被转换为 double 类型
+ 否则，如果任一操作数是 float 类型，其他操作数将被转换为 float 类型
+ 否则，如果任一操作数是 long 类型，其他操作数将被转换为 long 类型
+ 否则，所有操作数将被转换为 int 类型

## 注意

+ 自动类型转换只发生在兼容类型之间
+ 例如，从较小的数据类型（如 int）到较大的数据类型（如 long 或 double）的转换是安全的
+ 因为较大的数据类型可以容纳较小数据类型的所有可能值

  ```java
  byte -> short -> int -> long -> float -> double
  char -> int -> long -> float -> double
  ```
