# 字符 char

## 概述

+ char 本质是一个整数，即在输出的时候是 unicode 码对应的字符 https://tool.chinaz.com/Tools/Unicode.aspx

  ```java
  char a = 'a' // 对应的 Unicode码是 97
  System.out.println((int)a); // 97


  char b = 97;
  System.out.println(b); // 'a'
  ```

## 字符型 存储的本质

+ 字符型 存储到计算机中，需要将字符对应的码值（整数）找出来，比如 'a'

  + 存储: 'a' -> 码值 97 -> 二进制 -> 存值
  + 读取: 二进制 -> 97 -> 'a' -> 显示

## 基本使用

+ 字符类型char表示一个字符(不区分英文、中文、符号)

  ```java
  char a = '我'
  char b = 'a'
  char c = '+'
  char d = '1'
  char d = '\t'
  ```

+ 注意char类型使用单引号 `'` ，且仅有一个字符，要和双引号 `"` 的字符串类型区分开

## 运算

+ char 类型是可以就行运算的，相当于一个整数，因为他对应有 Unicode

  ```java
  char a = 'a';
  // (a 转成 Unicode 的 97) + 10
  System.out.println(a + 10); // 107
  ```

  ```java
  char a = 'a' + 1;
  System.out.println((int)a); // '98'
  System.out.println(a); // 'b'
  ```
