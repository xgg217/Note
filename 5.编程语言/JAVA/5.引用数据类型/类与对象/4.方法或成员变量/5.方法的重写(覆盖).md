# 方法的重写(覆盖)

## 意义

+ 重写让程序可以面向接口/父类编程，运行时根据实际对象类型执行不同逻辑，是策略模式、模板方法模式等设计模式的基础

## 规则

+ 规则之方法名、参数列表： 子类方法 的 *形参列表* 、 *方法名* 与父类的完全一样

  ```java
  class A {
      public void hi() {

      }
  }

  class B extends A {
      // 覆盖父类的方法
      public void hi() {

      }
  }
  ```

+ 规则之返回值： 子类方法的 *返回值类型* 和父类方法返回类型一样（或父类返回类型的子类）

  + 例如 父类返回类型是 Object，子类返回类型是 String

  ```java
    class A {
      public Object hi() {

      }
  }

  class B extends A {
      // 覆盖父类的方法
      public String hi() {

      }
  }
  ```

+ 规则之访问权限：子类方法不能缩小父类方法的访问权限

  + 不能比父类更严格（可以相同或更宽松）

  ```java
  class A {
      protected void foo() {}
  }

  class B extends A {
      @Override
      public void foo() {}    // protected → public，合法（更宽松）
  }
  ```

+ 规则之异常： 不能抛出比父类更宽泛的受检异常（可以更少或更窄）

+ 规则之 `static` / `final` / `private` 不能被重写（ `static` 是隐藏， `private` 不可见）


+ 规则之构造方法：不能被重写

+ 规则之注解：建议加 `@Override` ，编译器会校验是否真的重写成功

  ```java
  class Parent {
      Parent copy() { return new Parent(); }
  }

  class Child extends Parent {
      @Override
      Child copy() { return new Child(); }   // 返回子类型，合法
  }
  ```
