# 重载 与 重写

## 概述

+ 区别

  ```java
              重载 Overload                     重写 Override
  发生范围    本类                              子类与父类之间
  方法名      必须一样                          必须一样
  形参列表    类型、个数、顺序 至少有一个不同   必须相同
  返回类型    无要求                            子类重新的方法返回类型与父类一致（或者是其子类）
  修饰符      无要求                            子类方法不能缩小父类方法的访问方位
  绑定时机    编译时（静态绑定）                运行时（动态绑定）
  ```
