# 方法的重写 或 覆盖

## 概述

+ 子类方法 的 *参数* 、 *名称* 与父类的完全一样

  ```java
  class A {
      public void hi() {

      }
  }

  class B extends A {
      // 覆盖父类的方法
      public void hi() {

      }
  }
  ```

+ 子类方法的 *返回值类型* 和父类方法返回类型一样（或父类返回类型的子类）

  + 例如 父类返回类型是 Object，子类返回类型是 String

  ```java
    class A {
      public Object hi() {

      }
  }

  class B extends A {
      // 覆盖父类的方法
      public String hi() {

      }
  }
  ```

+ 子类方法不能缩小父类方法的访问权限
