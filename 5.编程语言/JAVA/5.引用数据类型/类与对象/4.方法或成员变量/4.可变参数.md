# 可变参数

## 概述

+ java 允许将同一个类中 *多个同名* *同功能* 但 *参数个数不同* 的方法，封装成一个方法
+ 就可以通过可变参数实现

## 语法

+ 语法

  ```java
  访问修饰符 返回类型 方法名(数据类型... 形参名) {

  }
  ```

+ 实参可以为 0-多个
+ 可变参数实参可以为数组（直接传入数组）

  ```java
  f1(int... nums) {}

  int[] arr = {1,2,3};

  f1(arr);
  ```

+ 可变参数的本质就是数组

  ```java
  // 形参表示可以输入 0-多个 int
  // nums 可以当做数组来使用
  int sum(int... nums) {
    // nums.length
  }
  ```

+ 可变参数可以和普通的参数一起放在形参列表，但必须保证可变参数在最后

  ```java
  int sum(String str, int... nums) {

  }
  ```

+ 一个形参列表只能出现一个可变参数

## 解决的问题

+ 解决的问题

  ```java
  // 2个数之和
  int sum(int n1, int n2) {
    return n1 + n2;
  }

  // 3个数之和
  int sum(int n1, int n2, int n3) {
    return n1 + n2 + n3;
  }

  // 4个数之和
  int sum(int n1, int n2, int n3, int n4) {
    return n1 + n2 + n3 + n4;
  }
  ```
