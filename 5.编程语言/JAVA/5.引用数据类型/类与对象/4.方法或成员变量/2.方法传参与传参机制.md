# 方法传参 与 传参机制

## 参数列表

+ 一个方法可以有0个参数，也可以有多个参数，
+ 参数类型可以为任意类型

  ```java
  printArr(int[][] map){}
  ```

+ 调用带参数的方法时，一定对应着参数列表传入相同类型的或者兼容类型的参数

+ 实参与形参的类型一定要一致或兼容，个数顺序必须一致

## 传参机制

+ 基本数据类型：传递的值是值拷贝，形参的任何改变都不影响实参

  ```java
  class AA {
      void swap(int a, int b) {
          System.out.println(a); // 10
          System.out.println(b); // 20
          int tmp = a;
          a = b;
          b = tmp;
          System.out.println(a); // 20
          System.out.println(b); // 10
      }
  }

  AA aa = new AA();
  int a = 10;
  int b = 20;
  aa.swap(a, b);
  System.out.println(a); // 10 函数内的变化不影响外面的值
  System.out.println(b); // 20
  ```

+ 引用类型:传递的是内存地址，所以可以通过形参影响实参

  ```java
  class AA {
      void swap(int[] arr) {
          arr[0] = 200;
          System.out.println(Arrays.toString(arr)); // [200, 2, 3]
      }
  }

  int[] arr = {1,2,3};
  AA aa = new AA();

  aa.swap(arr);
  System.out.println(Arrays.toString(arr)); // [200, 2, 3] 被函数内的操作影响到了
  ```
