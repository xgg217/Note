# 重载

## 概述

+ java 允许同一个类中多个同名方法的存在，但要求 形参列表不一致

  ```java
  System.out.println(100);
  System.out.println('h');
  System.out.println("hello");
  System.out.println(1.1);
  System.out.println(true);
  ```

## 重载的好处

+ 减轻了起名字的麻烦
+ 减轻了记名字的麻烦

## 注意事项

+ 方法名：必须相同
+ 形参列表：必须不同（参数类型、个数、顺序 至少有一个不同，参数名无要求）
+ 返回类型：无要求

## 使用

+ 使用

  ```java
  class MyCalculator {
      // int + int 之和
      int calculate(int n1, int n2) {
          return n1 + n2;
      };

      // int + double 之和
      double calculate(int n1, double n2) {
          return n1 + n2;
      };

      // double + int 之和
      double calculate(double n1, int n2) {
          return n1 + n2;
      };

      // 3个 int 之和
      int calculate(int n1, int n2, int n3) {
          return n1 + n2 + n3;
      };
  }

  MyCalculator m = new MyCalculator();

  m.calculate(1,1);
  m.calculate(1,1.1);
  m.calculate(1.1,1);
  m.calculate(1,1,1);
  ```
