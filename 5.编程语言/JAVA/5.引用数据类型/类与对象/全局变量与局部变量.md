# 全局变量与局部变量

## 作用域分类

+ 全局变量

+ 局部变量

## 全局变量-属性

+ 全局变量：也就是属性，作用域为整个类

  ```java
  class Cat {
    // 范围为整个 类
    int age = 10;

    void eat() {
      // 可以访问 到 age
      System.out.println(age)
    }
  }
  ```

+ 全局变量（属性）可以不赋值，直接使用，因为有默认值


  ```java
  class Cat {
    // 范围为整个 类
    int age; // 默认值 0

    void eat() {
      System.out.println(age); // 0
    }
  }
  ```

## 局部变量

+ 局部变量：也就是除了属性之外的其它变量，作用域为定义它的代码块中

  ```java
  car() {
    int n = 10; // 局部变量
    String name = "jack"; // 局部变量
  }
  ```

+ 局部变量一般是指在成员方法中定义的变量

  + 必须赋值后才能使用，因为没有默认值

  ```java
  class Cat {
      void eat() {
          int c;
          System.out.println(c); // 报错 未初始化变量c
      }
  }
  ```

## 注意事项

+ 属性和局部变量可以重名，访问时遵循就近原则

  ```java
  class Cat {
      int c = 10;
      void eat() {
          int c = 20;
          System.out.println(c); // 20
      }
  }
  ```

+ 在同一个作用域中（例如同一个方法中）局部变量不能重名

  ```java
  class Cat {
      void eat() {
          int c = 20;
          int c = 30; // 报错 重复定义变量
          System.out.println(c); // 20
      }
  }
  ```

+ 生命周期

  + 属性的生命周期较长，伴随着对象的创建而创建，伴随的对象的消失而消失
  + 局部变量的生命周期较短，在一次方法调用过程中（伴随着代码块 的执行而创建，代码块结束而消失）

+ 修饰符不同

  + 属性可以加修饰符
  + 局部变量不能用加修饰符
