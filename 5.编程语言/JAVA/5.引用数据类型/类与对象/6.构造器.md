# 构造器

## 概述

+ 构造方法也叫构造器(constructor) 是类的一种特殊的方法，
+ 主要作用就是完成对新对象的初始化

## 语法

+ 语法

  ```java
  [修饰符] 方法名(形参) {
    // 代码
  }
  ```

+ 构造器没有返回值
+ 方法名必须和类名 一样
+ 在创建对象时，系统会自动的调用该类的构造器完成对对象的初始化

  ```java
  class Person {
      String name;
      int age = 0;

      // 构造器
      public Person(String n, int a) {
          this.name = n;
          this.age = a;
      }
  }

  Person p = new Person("小明", 10);
  System.out.println(p.name); // 小明
  System.out.println(p.age); // 10
  ```

## 注意事项

+ 一个类可以定义多个构造器，即构造器重载

  ```java
  class Person {
      String name;
      int age = 0;

      // 构造器1
      public Person(String n, int a) {
          this.name = n;
          this.age = a;
      }

      // 构造器2
      public Person(String n) {
          this.name = n;
      }
  }

  // 构造器1
  Person p = new Person("小明", 10);

  // 构造器2
  Person p2 = new Person("小明");
  ```

+ 构造器是完成对象的初始化，并不是创建对象
+ 在创建对象时，系统自动的调用该类的构造方法

+ 如果class没有定义构造方法，系统会自动给类生成一个默认无参的构造方法（即默认构造方法）

  ```java
  class Person {
      String name;
      int age = 0;

      // 系统会默认生成
      public Person(){}
  }
  ```

+ 一旦定义了自己的构造器，默认的构造器就会被覆盖，就不能再使用默认的无参构造器，除非显示的定义一个无参的构造器 `Person(){}`
