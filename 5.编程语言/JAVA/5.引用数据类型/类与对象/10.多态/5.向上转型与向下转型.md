# 向上转型 与 向下转型

## 向上转型 语法

+ `父类类型 引用名 = new 子类类型();`

+ 可以调用父类中的所有成员（需遵守访问权限）
+ 不能调用子类特有成员
+ 最终运行效果看子类的具体实现

## 向下转型 语法

+ `子类类型 引用名 = (子类类型) 父类引用;`

+ 只能强转父类的引用，不能强转父类的对象
+ 要求父类的引用必须指向的是当前目标类型的对象

  ```java
  Animal animal = new Cat();

  // 正确的向下转型
  Cat animal1 = (Cat) animal;

  // 错误的向下转型
  Dog animal1 = (Dog) animal; // 编译错误
  ```

+ 当向下转型后，可以调用子类中所有成员

## 示例

+ 示例

  ```java
  public class Animal {
      String name = "动物";
      int age = 10;

      // 私有
      private void sleep() {
          System.out.println("碎觉");
      }

      public void run() {
          System.out.println("跑");
      }

      public void eat() {
          System.out.println("吃");
      }

      public void show() {
          System.out.println("你好");
      }
  }

  public class Cat extends Animal {
      public void eat() {
          System.out.println("猫吃鱼");
      }

      public void catchMouse() {
          System.out.println("猫抓老鼠");
      }
  }

  // 向上转型：父类引用指向子类对象
  {
      Animal animal = new Cat();

      // 无法调用，因为在父类中该方法是私有的
      animal.sleep();
      animal.run(); // 调用父类的方法
      animal.eat(); // 调用 子类的方法（子类重写了父类的方法）
      animal.show(); // 调用父类的方法

      // 在编译阶段，能调用哪些成员是由编译类型决定的
      // animal.catchMouse(); // 无法调用-解决办法，向下转型
  }

  // 向下转型
  {
    // 编译类型是 Cat，运行类型 也是 Cat
    Cat animal1 = (Cat) animal;
    animal1.catchMouse();
  }
  ```
