# 基础

## 概述

+ 指同一操作作用于不同对象，产生不同的执行结果

+ 多态的本质是：父类引用指向子类对象，调用方法时根据对象的实际类型决定执行哪个实现，而不是引用变量的声明类型

## 多态的优点

+ 可替换性：同一父类引用可指向不同子类对象

+ 可扩展性：新增子类无需修改调用方代码（开闭原则）

+ 消除类型判断：不必写大量 `if (type == ...)` ，交给多态自动分派

+ 降低耦合：调用方只依赖抽象（父类/接口）

## 多态的三个必要条件

+ 继承
+ 重写
+ 向上转型

  ```
  条件        说明
  继承        子类继承父类，或实现接口
  重写        子类重写父类的方法
  向上转型    父类引用指向子类对象（`Animal a = new Dog()` `Object obj = new Dog()`）
  ```
