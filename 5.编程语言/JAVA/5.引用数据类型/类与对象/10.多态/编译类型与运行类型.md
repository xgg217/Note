# 编译类型 与 运行类型

## 概述

+ 编译类型 与 运行类型

  ```java
  Animal a = new Dog();
  //  ↑          ↑
  // 编译类型    运行类型
  ```

+ 编译类型由变量声明决定，编译后固定

+ 运行类型由 new 出来的对象决定，运行时可变化（重新赋值）

## 编译类型的作用

+ 编译期，编译器只认编译类型，它决定：

  + 能调用哪些方法/访问哪些成员

    ```java
    Animal a = new Dog();
    a.speak();       // ✅ Animal 中声明了 speak
    a.wagTail();     // ❌ 编译错误：Animal 没有 wagTail
    ```

  + 方法重载的选择

    ```java
    void f(Animal a) { System.out.println("f(Animal)"); }
    void f(Dog d)    { System.out.println("f(Dog)"); }

    Animal a = new Dog();
    f(a);            // f(Animal) —— 看编译类型 Animal
    ```

  + 类型检查与转型合法性

    ```java
    Animal a = new Dog();
    Dog d = (Dog) a;    // 编译通过（Animal 与 Dog 有继承关系）
    String s = (String) a; // ❌ 编译错误：无继承关系
    ```

## 运行类型的作用

+ 运行期，JVM 认运行类型，它决定：

  + 实例方法的实际执行（动态绑定）

    ```java
    class Animal { void speak() { System.out.println("Animal"); } }
    class Dog extends Animal {
        @Override void speak() { System.out.println("Dog"); }
    }

    Animal a = new Dog();
    a.speak();       // 输出 Dog —— 运行类型是 Dog
    ```

  + instanceof 判断

    ```java
    Animal a = new Dog();
    System.out.println(a instanceof Dog);    // true（看运行类型）
    System.out.println(a instanceof Cat);    // false
    ```

  + 向下转型的运行时检查

    ```java
    Animal a = new Dog();
    Dog d = (Dog) a;         // 运行类型是 Dog，转型成功

    Animal b = new Cat();
    Dog d2 = (Dog) b;        // 运行类型是 Cat，抛 ClassCastException
    ```
