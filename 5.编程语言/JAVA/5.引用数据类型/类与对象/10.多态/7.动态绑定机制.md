# 动态绑定机制

## 概述

+ 动态绑定（Dynamic Binding），也叫后期绑定或运行时绑定，是 Java 实现多态的核心机制

+ 当调用对象方法的时候，该方法会和该对象的内存地址/运行类型绑定
+ 当调用对象属性时，没有动态绑定机制，哪里声明，哪里使用

  ```java
  class A{
      public int i = 10;
      public int sum() {
          return this.getL() + 10;
      }

      public int sum1() {
          return i + 10;
      }

      public int getL() {
          return i;
      }
  }

  class B extends A{
      public int i = 20;

  //    public int sum() {
  //        return getL() + 20;
  //    }

      public int getL() {
          return i;
      }

  //    public int sum1() {
  //        return i + 10;
  //    }
  }

  A a = new B();
  System.out.println(a.sum()); // 30

  System.out.println(a.sum1()); // 20
  ```
