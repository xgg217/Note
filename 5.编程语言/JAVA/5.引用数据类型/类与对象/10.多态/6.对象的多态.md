# 对象的多态

## 概述

+ 一个对象的 *编译类型* 和 *运行类型* 可以不一致

  ```java
  // animal 编译类型是 Animal，运行类型 Dog
  Animal animal = new Dog();
  ```

+ 编译类型在定义对象时就确定了，不能改变
+ 运行类型是可以变化的
+ 编译类型看定义时 `=` 的左边（声明类型），运行类型看 `=` 右边（实际对象类型）

  ```java
  // animal 编译类型是 Animal，运行类型 Dog
  Animal animal = new Dog();

  // animal  运行类型变成了 Cat, 编译类型是 Animal，
  animal = new Cat();
  ```

## 示例

+ 示例

  ```java
  public class Animal {
      public void cry() {
          System.out.println("Animal 动物在叫");
      }
  }

  public class Cat extends Animal {
      public void cry() {
          System.out.println("Cat 叫");
      }
  }

  public class Dog extends Animal {
      public void cry() {
          System.out.println("Dog 叫");
      }
  }

  // animal编译类型是 Animal，运行类型是 Dog
  Animal animal = new Dog();

  // 因为运行时，执行到改行时，animal运行类型就是Dog，所以cry就是Dog的方法cry
  animal.cry(); // Dog 叫

  // animal编译类型是 Animal，运行类型是 Cat
  animal = new Cat();
  animal.cry(); // Cat 叫
  ```
