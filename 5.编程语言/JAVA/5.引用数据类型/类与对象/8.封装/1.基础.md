# 封装

## 概述

+ 就是把抽象出来的数据（属性）和对数据的操作（方法）封装在一起
+ 数据被包含在内部，程序的其它部分只有通过被授权的操作（方法）才能对数据进行操作

## 封装的好处

+ 隐藏实现细节
+ 可以对数据进行验证，保证安全合理

## 封装的步骤

+ 步骤1：将属性进行私有化 `private`（不能直接修改属性）
+ 步骤2：提供一个公共的set方法，用于对属性判断并赋值

  ```java
  publi void setXxx(类型 参数) {
      // 数据验证...

      属性 = 参数
  }
  ```

+ 步骤3：提供一个公共的get方法，用于获取属性的值

  ```java
  publi 类型 getXxx() {
      // 权限判断

      return xx
  }
  ```

## 示例

+ 示例

  ```java
  class Test2 {
      // 步骤1 私有方法
      private int n1;

      public void Test2() {

      }

      public Test2(int n1) {
          this.setN1(n1);
      }

      // 步骤2 提供 set 方法
      public void setN1(int n) {

          this.n1 = n;
      }

      // 步骤3 提供 get 方法
      public int getN1() {
          return this.n1;
      }
  }
  ```
