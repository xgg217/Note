# 属 性或 成员变量

## 叫法

+ 属性 == 成员变量 == field字段

## 概述

+ 属性是类的一个组成部分，一般是基本数据类型，也可以是引用类型（对象、数组）

  ```java
  // 类定义
  class Student {
      // 属性（成员变量）
      String name;
      int age;
      String[] master;

      // 方法（行为）
      void study() {
          System.out.println(name + " 在学习");
      }
  }
  ```
