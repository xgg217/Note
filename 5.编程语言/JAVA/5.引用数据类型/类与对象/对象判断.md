# 对象判断

## instanceOf

+ 用于判断对象的 *运行类型* 是否为xx类或者xx类型的子类型

+ 语法 `object instanceof ClassName`

  + 返回 boolean 值： `true` 表示对象是该类（或其子类/实现类）的实例， `false` 表示不是

  + 注意：如果 `object` 为 `null` ， `instanceof` 始终返回 `false`

  ```java
  Object obj = "Hello";

  if (obj instanceof String) {
      String s = (String) obj;
      System.out.println(s.length());
  }
  ```

  ```java
  class AA {}
  class BB extends AA {}

  BB bb = new BB();

  System.out.println(bb instanceof BB); // true
  System.out.println(bb instanceof AA); // true

  AA aa = new BB();
  System.out.println(aa instanceof AA); // true
  System.out.println(aa instanceof BB); // true
  ```

+ 规则与限制

  ```java
  规则              说明
  null 判断         `null instanceof X` 永远为 `false`
  编译期检查        如果编译器能确定类型不可能匹配（如 `String` 变量判断 `instanceof Integer`），会编译报错
  数组              `arr instanceof int[]` 可以判断数组类型
  基本类型          不能用于基本类型（ `int` 、 `double` 等），只能用于引用类型
  模式变量作用域    模式变量在 `&&` 右侧、 `if` 块内、取反提前返回后可用
  ```
