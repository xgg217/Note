# 基础

## 概述

+ 一个程序就是一个世界，有很多事物（对象[属性,行为]）

  ```java
  // 类定义
  class Student {
      // 属性（成员变量）
      String name;
      int age;

      // 构造器
      public Student() {

      }

      // 方法（行为）
      public void study() {
          System.out.println(name + " 在学习");
      }
  }

  // 实例化 / 创建对象
  Student s = new Student();  // s 是对象引用
  s.name = "张三";
  s.age = 20;
  s.study();  // 输出：张三 在学习
  ```

## 类与对象

+ 类：Class 对象的模板/蓝图，定义属性（字段）和行为（方法）

+ 对象（Object）类的实例，通过 new 创建，占用内存
