# 数据循环

## for

+ for

  ```java
  int[] arr = {1, 2, 3, 4, 5};
  for (int i = 0; i < arr.length; i++) {
      System.out.println(arr[i]);
  }
  ```

## for-each

+ for-each，只读遍历

  ```java
  int[] arr = {1, 2, 3, 4, 5};
  for (int x : arr) {
      System.out.println(x);
  }
  ```

+ for-each 中修改元素值对基本类型数组无效（拿到的是副本）；对引用类型数组，修改对象内部属性有效

  ```java
  int[] nums = {1, 2, 3};
  for (int x : nums) x = 0;              // ❌ nums 不变
  System.out.println(Arrays.toString(nums));   // [1, 2, 3]

  for (int i = 0; i < nums.length; i++) nums[i] = 0;   // ✅
  ```


## 倒序遍历

+ 倒序遍历

  ```java
  int[] arr = {1, 2, 3, 4, 5};
  for (int i = arr.length - 1; i >= 0; i--) {
      System.out.println(arr[i]);
  }
  ```
