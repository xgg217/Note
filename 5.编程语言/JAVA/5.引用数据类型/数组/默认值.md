# 默认值

## 概述

+ 数组创建后，如果没有赋值，会有默认值

  ```java
  元素类型                  默认值
  byte/short/int/long       0
  float/double              0.0
  char                      '\u0000'
  boolean                   false
  引用类型                  null
  ```

  ```java
  int[] a = new int[5]; // [0, 0, 0, 0, 0]
  String[] s = new String[3];     // [null, null, null]
  ```
