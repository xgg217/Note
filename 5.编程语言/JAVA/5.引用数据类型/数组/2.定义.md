# 定义

## 创建

+ 创建

  ```java
  // ① 声明 + 分配长度（元素自动初始化为默认值）
  int[] a = new int[5];           // [0, 0, 0, 0, 0]
  String[] s = new String[3];     // [null, null, null]

  // ② 声明 + 初始化（静态初始化，长度由元素个数决定）
  int[] b = {1, 2, 3, 4, 5};
  int[] c = new int[]{1, 2, 3};

  // ③ 先声明后赋值
  int[] d;
  d = new int[]{1, 2, 3};         // ✅ 可以
  // d = {1, 2, 3};               // ❌ 编译错误，静态初始化只能用于声明时
  ```

## 方式1 动态初始化

+ 动态初始化

  ```java
  数据类型 数组名[] = new 数据类型[大小];

  int a[] = new int[5]; // 创建一个名字为a，长度为5的数组
  // 数组里面的值 {0,0,0,0,0}
  ```

## 方式2:动态初始化

+ 步骤1: 先声明数组（这时还没有分配存储空间） `数据类型 数组名[]` 或 `数据类型 数组名`

  ```java
  int a[]; // a 还是 null
  int[] a;

  // 这时 a 还不能使用，因为还没有初始化
  ```

+ 步骤2:创建数组（分配了内存空间） `数组名 = new 数据类型[大小]`

  ```java
  a = new int[10];
  ```

## 方式3 静态初始化

+ 初始化数组

  ```java
  // 方式1
  数据类型 数组名[] = {元素1, 元素2, 元素3, ...};

  // 方式2
  数据类型[] 数组名 = {元素1, 元素2, 元素3, ...};
  ```

  ```java
  int[] a = {1, 2, 3};

  // 相当于
  int[] a = new int[3];
  a[0] = 1;
  a[1] = 2;
  a[2] = 3;
  ```
