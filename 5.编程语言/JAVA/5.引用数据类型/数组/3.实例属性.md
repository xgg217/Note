# 属性

## 数组的访问

+ 访问

  ```java
  int[] a = {1, 2, 3};
  a[2]; // 3
  ```

+ 修改

  ```java
  int[] a = {1, 2, 3};
  arr[2] = 99; // {1, 2, 99}
  ```

+ 最后一个元素

  ```java
  int[] a = {1, 2, 3};
  a[a.length - 1]; // 3
  ```

+ 索引范围是 0 ~ length-1，越界会抛 ArrayIndexOutOfBoundsException

  ```java
  int[] arr = {1, 2, 3};
  System.out.println(arr[5]);      // ❌ 运行时异常
  ```

## 数组长度 length

+ 数组长度

  ```java
  int[] a = {1, 2, 3};
  a.length; // 3
  ```
