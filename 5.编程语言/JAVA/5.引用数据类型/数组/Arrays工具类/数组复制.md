# 数组复制

## 概述

+ 数组复制

  ```java
  int[] src = {1, 2, 3, 4, 5};

  // ① System.arraycopy（最快，底层 native）
  int[] dst1 = new int[5];
  System.arraycopy(src, 0, dst1, 0, src.length);

  // ② Arrays.copyOf（常用，可扩容）
  int[] dst2 = Arrays.copyOf(src, 3);         // [1, 2, 3]（截断）
  int[] dst3 = Arrays.copyOf(src, 8);         // [1,2,3,4,5,0,0,0]（补默认值）

  // ③ Arrays.copyOfRange
  int[] dst4 = Arrays.copyOfRange(src, 1, 4); // [2, 3, 4]

  // ④ clone()
  int[] dst5 = src.clone();
  ```

  ```java
  方法                    特点
  System.arraycopy        最快，需预分配目标数组，支持部分复制
  Arrays.copyOf           可扩容/截断，返回新数组
  clone()                 简单复制，返回同类型新数组
  Arrays.copyOfRange      复制指定区间
  ```
