# 基础

## 概述

+ 数组属于引用类型，数组型数据是对象(object)
+ 数组可以存放多个同一类型（包括基本类型和引用类型）的数据，但不能混用

  ```java
  // 报错 因为1.1是 double 类型
  int[] arr = {1,2,3, 1.1};

  // 正确 满足要求自动类型转换，因为
  double[] arr1 = {1.1, 2.2, 3};
  System.out.println(arr1[2]);
  ```

+ 数组也是一种数据类型，是引用类型
+ 即：数组就是一组数据

  ```java
  // double类型的数组
  double[] hens = { 3, 5, 1, 3.4, 2,50 };
  ```
