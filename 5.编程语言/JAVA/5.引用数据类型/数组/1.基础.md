# 基础

## 声明

+ 声明

  ```java
  // 推荐写法：类型[] 变量名
  int[] arr1;
  String[] arr2;

  // 也可（C 风格，不推荐）
  int arr3[];
  ```

## 创建

+ 创建

  ```java
  // ① 声明 + 分配长度（元素自动初始化为默认值）
  int[] a = new int[5];           // [0, 0, 0, 0, 0]
  String[] s = new String[3];     // [null, null, null]

  // ② 声明 + 初始化（静态初始化，长度由元素个数决定）
  int[] b = {1, 2, 3, 4, 5};
  int[] c = new int[]{1, 2, 3};

  // ③ 先声明后赋值
  int[] d;
  d = new int[]{1, 2, 3};         // ✅ 可以
  // d = {1, 2, 3};               // ❌ 编译错误，静态初始化只能用于声明时
  ```
