# 三元运算符

## 语法

+ `条件表达式 ? 表达式1 ： 表达式2；`

  + 如果表达式为 `true` ，运算后的结果是 表达式1
  + 如果表达式为 `false` ，运算后的结果是 表达式2

  ```java
  int a = 10;
  int b = 99;

  // 步骤1 a > b 为 false
  // 步骤2 返回 b--，先返回 b的值，然后再 b - 1
  // 步骤3 结果 99
  int result = a > b ? a++ : b--;
  ```

## 细节

+ 表达式1 和 表达式2 要为可以赋给接收变量的类型（可以自动转换，或者强制转换）

  ```java
  // 强制转换
  int c = 8 > 9 ? int(1.1) : (int)3.4;

  // 自动转换
  double c = 8 > 9 ? 1.1 : 3.4;
  ```
