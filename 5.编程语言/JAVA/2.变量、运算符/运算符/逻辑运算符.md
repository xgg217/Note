# 逻辑运算符

## 概述

+ 用于连接多个条件（多个关系表达式），最终的结果也是 `boolean`

## 运算符

+ `&&` 短路与

+ `||` 短路或

+ `!` 取反

+ `&` 逻辑与

+ `|` 逻辑或

+ `^` 逻辑异或

## && 短路与

+ `a&&b`

  + 当 a 和 b 同时为 `true` ，则结果为 `ture` ，否则为 `false`
  + 如果 a 为 `false` ，则不会计算 b，直接返回 `false`
  + 只有当 a 为 `true` 时，才会继续计算 b

    ```java
    int i = 0;
    boolean b1 = false && (i++ > 0);  // i 仍为 0（右边没执行）
    boolean b2 = false &  (i++ > 0);  // i 变为 1（右边执行了）
    ```

  + 当 a 和 b 同时为 `true` , 则结果 `true` ，否则为 `false`

  ```java
  if (obj != null && obj.getValue() > 0) {
      // 安全：obj 为 null 时，右边不会执行，不会抛 NPE
  }
  ```

+ 使用场景：条件判断

## & 逻辑与

+ `a&b`

  + 当 a 和 b 同时为 `true` ，则结果为 `ture` ，否则为 `false`
  + 无论 a 的结果如何，b 一定会被计算（没有短路）

    ```java
    int i = 0;
    boolean b1 = false && (i++ > 0);  // i 仍为 0（右边没执行）
    boolean b2 = false &  (i++ > 0);  // i 变为 1（右边执行了）
    ```

  + 当 a 和 b 同时为 `true` , 则结果 `true` ，否则为 `false`


  ```java
  if (obj != null & obj.getValue() > 0) {
      // 危险：即使 obj 为 null，右边仍会执行，可能抛 NullPointerException
  }
  ```

+ 使用场景：按位运算 / 强制求值

### && 与 & 区别

+ 规则

  + `&&` 只能用于布尔逻辑运算
  + `&` boolean 和整数类型（int、long、byte、short、char）,用于整数时是按位与；用于 boolean 时是非短路逻辑与

  ```java
  int i = 0;
  boolean b1 = false && (i++ > 0);  // i 仍为 0（右边没执行）
  boolean b2 = false &  (i++ > 0);  // i 变为 1（右边执行了）
  ```

## || 短路或

+ `a||b;`

  + 当 a 和 b ，有一个是 `true` ，则结果为 `ture` ，否则为 `false`
  + 如果 a 为 `true` ，则不会计算 b，直接返回 `true`

  + 只有当 a 为 `false` 时，才会继续计算 b

  ```java
  int i = 0;
  boolean b1 = true || (i++ > 0);  // i 仍为 0（右边没执行）
  boolean b2 = true |  (i++ > 0);  // i 变为 1（右边执行了）
  ```

+ 使用场景：只能用于布尔逻辑运算

## | 逻辑或

+ `a|b;`

  + 当 a 和 b ，有一个是 `true` ，则结果为 `ture` ，否则为 `false`
  + 无论 a 的结果如何，b 一定会被计算

  ```java
  int i = 0;
  boolean b1 = true || (i++ > 0);  // i 仍为 0（右边没执行）
  boolean b2 = true |  (i++ > 0);  // i 变为 1（右边执行了）
  ```

+ 使用场景：用于整数时是按位或；用于 boolean 时是非短路逻辑或

## ! 取反

+ 作用是把布尔值取反

  + `!true` → `false`

  + `!false` → `true`

  ```java
  boolean a = true;
  boolean b = !a;      // false

  boolean c = !(1 > 2); // true
  ```

+ 适用类型：仅 boolean

## ^ 逻辑异或

+ 当 a 和 b 不同时，则结果为 `ture` ，否则为 `false`

## 总结

+ 总结

  ```java
  a       b         a&b      a&&b      a|b      a||b     !a       a^b
  true    true      true     true      true     true     false    false
  true    false     false    false     true     true     false    true
  false   true      false    false     true     true     true     true
  false   false     false    false     false    false    true     false
  ```
