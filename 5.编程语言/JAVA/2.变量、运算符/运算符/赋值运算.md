# 赋值运算

## 概述

+ 赋值运算符就是将某个运算后的值赋给指定的

## 运算符

+ `=`

  ```java
  int a = 10;
  ```

+ 复合赋值运算符

  + `+=`

    ```java
    a += b; // 等价于 a = a + b;
    ```

  + `-=`

    ```java
    a -= b; // 等价于 a = a - b;
    ```

  + `*=`
  + `/=`
  + `%=`

## 运算特点

+ 从右向左

  ```java
  int num = a + b + c;
  // 步骤1 计算 a + b + c 算出结果;
  // 步骤2 将结果 赋值给 num
  ```

+ 赋值运算符的左边只能是变量，右边可以是变量、表达式、常量值

  ```java
  int num = 20;
  int num2 = 7 * 9;
  int num3 = num2;
  ```

+ 复合赋值运算符会进行类型转换

  ```java
  byte b = 2;

  b += 3; // 等价于 b = (byte)(b + 3);

  b++; // 等价于 b = (byte)(b + 1);
  ```
