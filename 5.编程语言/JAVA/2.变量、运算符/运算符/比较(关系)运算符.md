# 比较(关系)运算符

## 概述

+ 关系运算符的结果都是boolean (`true` 或 `false` )

+ 关闭表达式经常用于 if 结果的条件中或循环结构的条件中

+ 关系运算符组成的表达式，我们称为 *关系表达式* `a > b`

## 运算符

+ `==` 相等于

  ```java
  8 == 7 // false
  ```

+ `!=` 不等于

  ```java
  8 != 7 // true
  ```

+ `<` 小于

  ```java
  8 < 7 // false
  ```

+ `>` 大于

  ```java
  8 > 7 // true
  ```

+ `<=` 小于等于

  ```java
  8 <= 7 // false
  ```

+ `>=` 大于等于

  ```java
  8 >= 7 // true
  ```

+ `instanceof` 检查是否是类的对象

  ```java
  "hsp" instanceof String // true
  ```
