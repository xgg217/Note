# 包命名

## 规则

+ 只能包含数字、字母、下划线、小圆点
+ 但不能数字开头，不能是关键字和保留字

  ```java
  // 错误 class 关键字
  demo.class.excel

  // 错误 数字开头
  demo.12a

  // 正确
  demo.abc.oa
  ```

## 命名规范

+ 一般是小写字母+小圆点

  ```java
  com.公司名.项目名.业务模块名

  com.hspedu.oa.model;
  com.hspedu.oa.controller;
  ```

  ```java
  com.sina.crm.user; // 用户模块
  com.sina.crm.order; // 订单模块
  com.sina.crm.utils; // 工具类
  ```
