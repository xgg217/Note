# 退出循环

## break

+ 在循环中：立即终止当前整个循环，跳到循环之后的语句

+ 在 switch 中：跳出 switch 块（防止穿透）

  ```java
  for (int i = 0; i < 10; i++) {
      if (i == 5) break;        // i==5 时整个循环结束
      System.out.println(i);    // 输出 0 1 2 3 4
  }
  System.out.println("循环结束");
  ```

  ```java
  int i = 0;
  while (true) {
      if (i >= 3) break;        // 死循环靠 break 退出
      System.out.println(i++);  // 0 1 2
  }
  ```

+ break 只能跳出最内层的循环/switch，多层嵌套需用标签

## continue

+ 跳过本次循环剩余的语句，直接进入下一次循环（对 for 会执行更新表达式；对 while 回到条件判断）

  ```java
  for (int i = 0; i < 5; i++) {
      if (i == 2) continue;     // 跳过 i==2 的本次
      System.out.println(i);    // 0 1 3 4
  }

  // 只处理偶数
  for (int i = 1; i <= 10; i++) {
      if (i % 2 != 0) continue;
      System.out.println(i);    // 2 4 6 8 10
  }
  ```

## return

+ 立即结束当前方法的执行，返回到调用处。有返回值的方法需带返回值

+ return 会跳出所有循环

  ```java
  public boolean contains(int[][] matrix, int target) {
      for (int[] row : matrix) {
          for (int x : row) {
              if (x == target) {
                  return true;   // 直接结束整个方法，跳出所有循环
              }
          }
      }
      return false;
  }
  ```
