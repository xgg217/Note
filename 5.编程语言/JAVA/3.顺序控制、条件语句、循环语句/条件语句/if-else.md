# if-else

## 单分支

+ 语法

  ```java
  if(条件表达式) {
    // 执行代码
  }
  ```

  ```java
  int age = 18;
  if(age > 19) {
    ...
  }
  ```

## 双分支

+ 语法

  ```java
  if(条件表达式) {
    // 执行代码
  } else {
    // 执行代码2
  }
  ```

## 多分支

+ 语法

  ```java
  if(条件表达式) {
    // 执行代码
  } else if(条件表达式2) {
    // 执行代码2
  } else if(条件表达式3) {
    // 执行代码3
  } else {
    // 执行代码n
  }
  ```

## 嵌套分支

+ 建议不要超过3层(可读性不好)

  ```java
  if() {
    if() {

    } else {

    }
  }
  ```
