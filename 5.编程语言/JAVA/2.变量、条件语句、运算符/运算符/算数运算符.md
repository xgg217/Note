# 算数运算符

## 运算符

+ `+` 正号

  ```java
  +7 // 结果 7
  ```

+ `-` 负号

  ```java
  b = 11;
  -b // 结果 -11
  ```

+ `+` 加

  ```java
  9 + 9; // 18
  ```

+ `-` 减

  ```java
  10 - 8; // 2
  ```

+ `*` 乘

  ```java
  7 * 8; // 56
  ```

+ `/` 除

  ```java
  9 / 9; // 1

  System.out.println(10 / 4); // 2

  double d = 10 / 4;
  System.out.println(d); // 2.0

  double d2 = 10.0 / 4;
  System.out.println(d2); // 2.5
  ```

+ `%` 取模（取余）

+ `++a` 自增前

+ `a++` 自增后

+ `--a` 自减前

+ `a--` 自减后

+ `+` 字符串拼接

  ```java
  "hsp" + "edu"; // hspedu"
  ```

### % 取模（取余）

+ `a % b` = `a - (a / b) * b`

  + a / b 采用 取整
  + 结果的符号永远与被除数 a 相同

  ```java
  11 % 9 // 2

  10 % 3 // 1

  // -10 - (-10 / 3) * 3 = -10 - -9 = -10 + 9 = -1
  -10 % 3 // -1

  10 % -3 // 1
  -10 % -3 // -1
  ```

### 自增

+ 场景1:作为独立的语句使用 `++i` 与 `i++` 完全等价于 `i = i + 1;`

  ```java
  int i = 10;
  i++; // 自增 等价于 i = i + 1;
  System.out.println(i); // 11
  ```

  ```java
  int i = 10;
  ++i; // 自增 等价于 i = i + 1;
  System.out.println(i); // 11
  ```

+ 场景2: 作为表达式使用

  + `i++` 先赋值，后自增

    ```java
    int i = 2;
    int j = i++; // temp = i; i = i + 1; j = temp;
    System.out.println(i); // 3
    System.out.println(j); // 2
    ```

  + `++i` 先自增，后赋值

    ```java
    int i = 2;
    int j = ++i; // i = i + 1; j = i;
    System.out.println(i); // 3
    System.out.println(j); // 3
    ```
