# 基础

## 分类

+ 局部变量

  + 需要初始化

+ 成员变量
+ 静态变量

## 变量定义

+ 定义并赋值

  ```java
  int x = 100; // 定义int类型变量x，并赋予初始值100

  // 重新赋值为200
  x = 200;
  ```

## 成员变量或者静态变量 默认值

+ 默认值

  ```
  数据类型  默认值      大小
  boolean   false       不确定
  char      '\u0000'     2 字节
  byte      0           1 字节
  short     0           2 字节
  int       0           4 字节
  long      0L          8 字节
  float     0.0f        4 字节
  double    0.0         8 字节
  ```
