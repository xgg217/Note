# 整数

## 概述

+ 对于整型类型，Java只定义了带符号的整型
+ 因此，最高位的bit表示符号位（0表示正数，1表示负数）

## 整数之1 byte

+ byte 占1个字节
+ 范围 -128 ~ 127

  ```java
  byte b; // 声明一个 byte 类型变量
  b = 10; // 将值 10 赋给变量 b
  byte c = -100; // 声明并初始化一个 byte 类型变量 c，赋值为 -100
  ```

+ 使用场景：年龄、状态码...

## 整数之2 short

+ short 占2个字节
+ 范围 -32768 ~ 32767

  ```java
  short s; // 声明一个 short 类型变量
  s = 1000; // 将值 1000 赋给变量 s
  short t = -2000; // 声明并初始化一个 short 类型变量 t，赋值为 -2000
  ```

+ 使用场景：短 ID

## 整数之3 int

+ 大部分开始时可以使用
+ int 占4个字节
+ -2147483648 ~ 2147483647

  ```java
  int i; // 声明一个 int 类型变量
  i = 1000000; // 将值 1000000 赋给变量 i
  int j = -2000000; // 声明并初始化一个 int 类型变量 j，赋值为 -2000000

  int i = 2147483647;
  int i2 = -2147483648;
  int i3 = 2_000_000_000; // 加下划线更容易识别
  int i4 = 0xff0000; // 十六进制表示的16711680
  int i5 = 0b1000000000; // 二进制表示的512
  ```

+ 使用场景：数量、索引

## 整数之4 long

+ long 占8个字节
+ -9223372036854775808 ~ 9223372036854775807
+ 末尾要带上大写的 `L`

  ```java
  long n1 = 9000000000000000000L; // long型的结尾需要加L
  long n2 = 900; // 没有加L，此处900为int，但int类型可以赋值给long
  int i6 = 900L; // 错误：不能把long型赋值给int
  ```

+ 使用场景：时间戳、大 ID
