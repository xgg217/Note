# 布尔

## 概述

+ 布尔类型boolean只有 `true` 和 `false` 两个值，布尔类型总是关系运算的计算结果

  ```java
  boolean b1 = true;
  boolean b2 = false;
  boolean isGreater = 5 > 3; // 计算结果为true
  int age = 12;
  boolean isAdult = age >= 18; // 计算结果为false
  ```

+ Java语言对布尔类型的存储并没有做规定，因为理论上存储布尔类型只需要1 bit，但是通常JVM内部会把boolean表示为4字节整数

## 注意

+ `true` 与 1 不能相互转换
