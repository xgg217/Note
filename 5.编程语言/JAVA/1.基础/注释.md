# 注释

## 单行注释

+ 以双斜线开头，直到这一行的结尾结束

  ```java
  // 单行注释
  ...
  ```

## 多行注释

+ 以 `/*` 星号开头，以 `*/` 结束，可以有多行

  ```java
  /*
  这是注释
  blablabla...
  这也是注释
  */
  ```

## 文档注释

+ 以 `/**` 开头，以 `*/` 结束，如果有多行，每行通常以星号开头

  ```java
  /**
   * 可以用来自动创建文档的注释
   *
   * @auther liaoxuefeng
   */
  public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
  }
  ```
