# JDK

## 安装

+ https://www.oracle.com/cn/java/technologies/downloads/

  + 可以安装到其他盘
  + 安装路径不要有中文或者特殊符合如空格

    ```
    d:\program\hspjdk8
    ```

  + 当提示安装 JRE 时，可以选择不安装

+ 或者

  ```bash
  winget install Microsoft.OpenJDK.21
  ```

  ```shell
  winget install EclipseAdoptium.Temurin.21.JDK
  ```
