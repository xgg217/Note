# 变量命名

## 命名规范

+ 英文
+ 数字
+ $
+ _

+ 区分大小写

## 类名要求

+ 类名必须以英文字母开头，后接字母，数字和下划线的组合

+ 建议：大驼峰式

  ```java
  // 好的类命名：
  Hello
  NoteBook
  VRPlayer

  // 不好的类命名：
  hello
  Good123
  Note_Book
  _World
  ```

## 方法名

+ 首字母小写

  ```java
  // 好的方法命名：
  main
  goodMorning
  playVR

  // 不好的方法命名：
  Main
  good123
  good_morning
  _playVR
  ```

## 变量名
