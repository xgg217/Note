# 标识符

## 概述

+ 标识符：JAVA 对各种变量、方法和类名等命名时使用的字符序列
+ 凡是自己可以起名字的地方都叫标识符

## 规则 必须遵守

+ 规则1:由 26个英文大小写（区分大小写）、0-9 、`_` 、`$` 组成
+ 规则2:不可以数字开头

  ```java
  // 错误
  int 3ab = 1;
  ```

+ 规则3: 不可以使用关键字和保留字
+ 规则4: 严格区分大小写，长度不限制
+ 规则5: 标识符不能包含空格

  ```java
  // 错误
  int a b = 10;
  ```

## 标识符命名规范

+ 包名：多单词组成时所有的字母都小写

  ```java
  aaa.bbb.ccc
  com.hsp.crm
  ```

+ 类名、接口名：首字母大写（大驼峰式）

  ```java
  Hello
  NoteBook
  VRPlayer
  ```

+ 变量名、方法名:小驼峰式

  ```java
  main
  goodMorning
  playVR
  ```

+ 常量名：所有的字母都大写，多个单词用下划线连接 `_`

  ```java
  XXX_YYY_ZZZ
  ```
