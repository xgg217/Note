# 查

## npm version 与 npm -v

+ npm version：查看当前 npm cli 的详细信息
+ 相比 npm -v 显示的信息要更丰富一些

## npm root

+ 查找本地或者全局安装的包的根目录
+ 查看全局的包目录的话，需要添加 -g

  ```bash
  npm root [-g]
  ```

## 查看全局安装的目录

+ 查看全局安装的目录

  ```bash
  npm config get prefix
  ```


## npm info

+ 查看某一个包的详细信息，这里所说的信息是指包版本、依赖项、作者、描述等信息，便于开发者选择合适的包

+ 可以查看所有包信息，没有安装的可也可看到

  ```bash
  npm view 包名 [子信息]
  ## view 别名 : v info show

  ## 例如
  npm v react
  npm v react name
  ```

## npm search

+ 这个命令是对包进行搜索，提供一个关键字，会搜索出所有和关键字相关的包

  ```bash
  npm search express
  ```

## npm outdated

+ 该命令可以用于检查当前项目中的依赖包是否过时，以及当前可用的最新版本

## npm ls 或 npm list

+ 可以罗列出当前项目安装的依赖包以及依赖包下层的依赖

  ```bash
  npm list [-g] [--depth=深度依赖]
  ## list 别名 : ls la ll

  npm ls
  npm la
  npm ll
  ```

+ 通过 `--depth 0/1/2` 来进行层级的调整，

  ```bash
  ## 查看0级依赖
  npm la --depth=0

  ## 查看1级依赖
  npm la --depth=1
  ```

+ 如果是 `npm ls -g` 罗列出全局的包

  ```bash
  npm la -g
  ```

+ 如果要查看某个模块的版本号

  ```bash
  npm list grunt
  ```
