# popup弹出窗口

## 概述

+ 在 Leaflet 里，`L.popup()` 是一个**弹出信息窗口**对象，用来在地图上显示一段 HTML 内容，可以**独立存在**，也可以绑定到地图元素（Marker、Polygon、Polyline 等）

  ```css
  L.popup()
    .setLatLng(center)
    .setContent('杭州市')
    .openOn(map)
  ```

+ 可以给多个要求分别添加弹出窗口：

  ```css
  L.geoJSON(hangzhou, {
    onEachFeature: (feature, layer) => {
      const center = (feature.properties.centroid || feature.properties.center).reverse()
      const name = feature.properties.name
      layer.on({
        click: () => {
          L.popup()
            .setLatLng(center)
            .setContent(name)
            .openOn(map)
        },
      })
    },
  }).addTo(map)
  ```
