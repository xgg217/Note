# 地图控件

## 概述

+ 在 Leaflet 中，“控件”是指固定在地图四个角落的 UI 组件，例如 **缩放按钮**、**比例尺**、**图层切换** 等
+ Leaflet 内置了一些常用控件，也可以加载多个不同的控件，甚至自定义控件



  ```javascript
  import 'leaflet.fullscreen'
  import 'leaflet.fullscreen/Control.FullScreen.css'

  const vecLayer = L.tileLayer(`http://t0.tianditu.gov.cn/vec_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=vec&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`, {
      attribution: '&copy; <a href="https://www.tianditu.gov.cn/">天地图</a>',
    }).addTo(map)

    const imgLayer = L.tileLayer(`http://t0.tianditu.gov.cn/img_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=img&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`, {
      attribution: '&copy; <a href="https://www.tianditu.gov.cn/">天地图</a>',
    })

  const tagLayer = L.tileLayer(`http://t0.tianditu.gov.cn/cva_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=cva&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`).addTo(map)

  L.control.scale({ position: 'bottomleft' }).addTo(map)

  L.control
    .fullscreen()
    .addTo(map)

  const baseMap = {
    "矢量图": vecLayer,
    "影像图": imgLayer,
  }

  const overlayMaps = {
    "标注层": tagLayer,
    "杭州市": L.marker(center)
  }

  L.control.layers(baseMap, overlayMaps, { position: 'topright' }).addTo(map)
  ```
