# marker标记点

## 概述

+ 在 Leaflet 中，Marker（标记）是地图上最常用的元素之一，用来在特定经纬度位置放置一个可见的点标记（通常是图标），可以配合 Popup、Tooltip 或自定义事件使用

  ```css
  import a from './assets/a.png'

  L.marker(center, {
    icon: L.icon({
      iconUrl: a,
      iconSize: [50, 50],
    }),
  }).addTo(map).bindPopup('杭州市')
  ```

+ 在地图上添加多个标记点：

  ```css
  const poi = [
    { name: '希望小学', lng: 124.789412, lat: 47.347325, type: 'school' },
    { name: '蜜雪冰城', lng: 103.007012, lat: 39.53535, type: 'school' },
    { name: '天猫超市', lng: 117.872028, lat: 27.100653, type: 'market' },
    { name: '如家酒店', lng: 124.642233, lat: 48.042886, type: 'market' },
    { name: '人民医院', lng: 87.038159, lat: 31.42261, type: 'hospital' },
    { name: '和平饭店', lng: 117.038159, lat: 31.62261, type: 'school' },
    { name: '银泰城', lng: 121.038159, lat: 29.42261, type: 'market' },
    { name: '海底捞', lng: 111.038159, lat: 28.42261, type: 'school' },
  ]

  function addPoi(data) {
    // 收集所有 marker 的坐标
    const positions = []
    data.forEach((d) => {
      let url = ""
      if (d.type === "market") {
        url = a
      } else if (d.type === "school") {
        url = b
      } else {
        url = c
      }
      const myIcon = L.icon({
        iconUrl: url,
        iconSize: [30, 30],
      })
      L.marker([d.lat, d.lng], {
        icon: myIcon,
      }).addTo(map).bindPopup(d.name)
      positions.push([d.lat, d.lng])
    })
    return positions
  }

  const positions = addPoi(poi)
  if (positions.length > 0) {
    map.fitBounds(positions)
  }
  ```
