# 事件

## 通用状态变更事件

+ 所有图层都继承自 BaseLayer，属性变化时会触发对应的 change: 事件：

  + change:visible：图层可见性改变时触发

  + change:opacity：图层透明度改变时触发

  + change:zIndex：图层渲染顺序改变时触发

  + change:extent：图层范围改变时触发

  + change:minResolution / change:maxResolution：分辨率约束改变时触发

  + change:source：图层数据源改变时触发

## 矢量图层（VectorLayer）特有事件

+ 矢量图层（ol/layer/Vector）额外支持要素相关的事件，用于监听矢量数据的变化：

+ 要素增删

  + featureadded：要素被添加到图层后触发，事件对象包含 feature 属性。

  + featureremoved：要素被移除后触发。

+ 要素交互（选中/修改）

  + featureselected / featureunselected：要素被选中或取消选中时触发。

  + featuremodified：要素被修改后触发。

  + vertexmodified：要素的顶点被修改时触发。

+ 草图事件（绘制过程中）

  + sketchstarted：开始绘制时触发。

  + sketchmodified：绘制过程中修改草图时触发。

  + sketchcomplete：草图绘制完成时触发
