# 属性

## 概述

+ 这些属性定义在 BaseLayer 上，所有子类图层均可使用。它们都是可观察（Observable） 的，意味着你可以监听它们的变化

## 通用显示属性

+ visible：布尔值，控制图层是否可见，默认 true

  + 对应 getVisible() / setVisible()

+ opacity：数字（0-1），控制图层透明度，默认 1（完全不透明）

  + 对应 getOpacity() / setOpacity()

+ zIndex：数字，控制图层渲染顺序，数值越大越靠前

  + 默认 0
  + 对应 getZIndex() / setZIndex()

## 范围与分辨率约束

+ extent：图层的渲染范围，图层不会在此范围外渲染

  + 对应 getExtent() / setExtent()

+ minResolution / maxResolution：图层可见的最小/最大分辨率

  + 注意：minResolution 是包含的（>=），maxResolution 是排除的（<）

+ minZoom / maxZoom：图层可见的最小/最大缩放级别，是分辨率的便捷替代

  + minZoom 包含，maxZoom 包含
