# WKT数据

## 概述

+ WKT（Well-Known Text）是一种用于表示**几何对象**（点、线、多边形等）的文本格式  ，给GeoJSON类似也是矢量数据的一种

  ```javascript
  import { VectorLayer } from 'ol/layer'
  import { Vector } from 'ol/source'
  import { WKT } from 'ol/format'

  const wkt = `POLYGON((120.29 30.34, 120.28 30.21, 120.40 30.21, 120.47 30.32, 120.29 30.34))`

  const vectorSource = new Vector({
    features: new WKT().readFeatures(wkt, {
      dataProjection: 'EPSG:4326',
      featureProjection: 'EPSG:3857',
    }),
  })
  ```
