# 初始化地图

## 概述

+ OpenLayers 是一个开源的 JavaScript 地图框架，用于在网页中构建强大的 WebGIS（地理信息系统）应用
+ 它能够加载各种地图服务和格式，如 OSM、天地图、WMTS、WMS、GeoJSON、KML 等，并支持丰富的地图交互和空间分析功能

+ 官方网址：https://openlayers.org/

## 名词解释

+ Map: 地图容器，绑定到 DOM 元素

+ View: 控制地图的中心、缩放、投影、旋转

+ Layer: 图层，如瓦片图层、矢量图层、影像图层

+ Source: 数据源，如 OSM、XYZ、GeoJSON、WMS

+ Feature: 矢量要素（点、线、面）

+ Geometry: 几何对象（Point、LineString、Polygon）

+ Style: 要素的渲染样式

+ Interaction: 交互，如拖拽、绘制、选择

## 投影方式

+  默认是Web墨卡托投影（EPSG：3857）

  ```js
  import Map from 'ol/Map.js';
  import View from 'ol/View.js';

  const map = new Map({
    view: new View({
      projection: 'EPSG:4326'
    })
  });
  ```

+ 修改默认投影

  ```js
  const map = new Map({
    view: new View({
      center: [0, 0],
      zoom: 2,
      projection: "EPSG:4326", // 使用wgs84坐标系
      extent,
    }),
  });
  ```
