# 初始化地图

## 概述

+ OpenLayers 是一个开源的 JavaScript 地图框架，用于在网页中构建强大的 WebGIS（地理信息系统）应用
+ 它能够加载各种地图服务和格式，如 OSM、天地图、WMTS、WMS、GeoJSON、KML 等，并支持丰富的地图交互和空间分析功能

+ 官方网址：https://openlayers.org/

## 基本使用

+ 下载openlayers框架

  ```shell
  npm install ol
  ```

+ map组件创建地图

  ```javascript
  import { Map, View } from 'ol'
  import { Tile as TileLayer } from 'ol/layer'
  import { OSM } from 'ol/source'

  new Map({
    target: 'map', // 对应HTML中<div>的id
    layers: [
      // 瓦片图层
      new TileLayer({
        // 数据源是 OSM
        source: new OSM() // 使用OpenStreetMap作为底图
      })
    ],
    view: new View({
      center: [0, 0],  // 地图初始中心点
      zoom: 2, // 初始缩放级别
    })
  })
  ```

+ CSS样式处理

  ```css
  /* style.css */
  @import "node_modules/ol/ol.css";
  ```
