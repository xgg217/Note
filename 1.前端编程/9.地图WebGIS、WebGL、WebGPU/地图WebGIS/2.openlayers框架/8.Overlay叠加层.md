# Overlay 叠加层

## 概述

+ 在 OpenLayers 中，`Overlay`（叠加层）用于将 **任意 HTML 元素（如弹窗、标签、按钮）** 放置在地图上的某个地理位置，随着地图平移或缩放自动定位，非常适合用于：

  + 信息窗口（InfoWindow）
  + 气泡弹窗（Popup）
  + 标签标注（Label）
  + 自定义 DOM 控件

## 基本使用

+ 步骤1: 创建 DOM 元素（通常是在 HTML 中预定义好的 div）

  ```html
  <div id="popup" class="ol-popup">...</div>
  ```

+ 步骤2: 创建 Overlay 实例

  ```js
  const popup = new Overlay({
    element: document.getElementById('popup'),
    autoPan: true // 可选：自动平移以确保弹窗可见
  });
  ```

+ 步骤3: 添加到地图

  ```js
  // 方式1
  map.addOverlay(popup);

  // 方式2
  const map = new Map({
    target: mapRef.value!,
    layers: [...],
    view: new View({
      center: coodPonit,
      // center: coordinate,
      zoom: 4,
    }),
    overlays: [popup],
  })
  ```

+ 步骤4: 在需要时设置坐标（例如地图点击事件中）

  ```js
  map.on('singleclick', (evt) => {
    popup.setPosition(evt.coordinate);
  });
  ```

## 关键配置项

+ element:绑定到 Overlay 的 DOM 元素，这是必需的

+ position: Overlay 锚定的地理坐标(地图投影下的 `[x, y]` )

+ positioning:定义元素相对于 position 的锚点位置

  + 默认 'top-left'（元素左上角对齐坐标点）
  + 常用 'bottom-center' 让弹窗底部尖端对准坐标

+ offset:像素单位的偏移量 `[x, y]`

  + 正值向右向下偏移，常用于微调弹窗箭头位置

+ autoPan:当调用 setPosition 时，若 Overlay 超出视野，地图自动平移使其可见

+ stopEvent:是否阻止事件传播到地图

  + 默认 true，这意味着在弹窗上滚动鼠标不会缩放地图
  + 若希望弹窗上的操作也触发地图事件，设为 `false`

## 示例

+ 示例1

  ```javascript
  import { Overlay } from 'ol'
  const overlay = new Overlay({
    element: info,
    positioning: 'bottom-center',
    // 地图边缘的时候，进行自动平移
    autoPan: {
      animation: {
        duration: 250,
      },
    },
  })

  map.on('pointermove', function (e) {
    const feature = map.forEachFeatureAtPixel(e.pixel, function (feat) {
      return feat instanceof Feature ? feat : null
    })
    if (feature) {
      const name = feature.get('name')
      info.innerHTML = name
      overlay.setPosition(e.coordinate)
      info.style.display = 'block'
    } else {
      overlay.setPosition(undefined)
      info.style.display = 'none'
    }
  })
  ```
