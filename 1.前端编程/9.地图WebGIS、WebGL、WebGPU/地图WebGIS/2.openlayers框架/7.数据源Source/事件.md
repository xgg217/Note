# 事件

## 要素增删 相关事件

+ addfeature：要素被添加到源时触发。事件对象包含 feature 属性。

  ```js
  import VectorSource from 'ol/source/Vector.js';

  const vectorSource = new VectorSource();

  vectorSource.on('addfeature', (event) => {
    const feature = event.feature;
    console.log('新要素加入:', feature.getId());
    console.log('几何类型:', feature.getGeometry().getType());
  });
  ```

+ removefeature：要素从源中移除时触发

  ```js
  vectorSource.on('removefeature', (event) => {
    console.log('要素被移除:', event.feature);
  });
  ```

+ clear：源被清空时触发

## 要素修改 相关事件

+ changefeature：源中某个要素发生变化时触发

  ```js
  vectorSource.on('changefeature', (event) => {
    console.log('要素已修改:', event.feature);
  });
  ```

+ change：源的任何变化（增删改）都会触发

  ```js
  vectorSource.on('change', () => {
    console.log('当前要素总数:', vectorSource.getFeatures().length);
  });
  ```

## 加载相关 相关事件

+ featuresloadstart：开始加载要素时触发

+ featuresloadend：要素加载完成时触发

  ```js

  const vectorSource = new Vector({
    url: hangzhou,
    format: new GeoJSON({
      dataProjection: "EPSG:4326", // 数据源是经纬度
      featureProjection: "EPSG:3857", // 地图是墨卡托
    }),
  });

  vectorSource.once("featuresloadend", () => {
    const extent = vectorSource.getExtent();
    if (extent && isFinite(extent[0])) {
      map.getView().fit(extent);
    }
  });
  ```

+ featuresloaderror：要素加载出错时触发

## addfeature 与 change 的区别

+ addfeature 与 change 的区别：addfeature 只在单个要素加入时触发；change 在任何变化（增删改、属性变化）时都会触发，粒度更粗

## 批量添加 事件监听

+ 如果一次性添加多个要素（如 `source.addFeatures([...])` ），addfeature 会为每个要素分别触发一次
+ 如果只想在批量操作后执行一次逻辑，可以监听 change 事件，或使用防抖处理
