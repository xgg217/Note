# 自定义矢量数据

## 概述

+ 除了使用OpenLayers框架允许的矢量数据格式，例如：GeoJSON、WKT以外
+ 也支持自定义矢量数据进行开发和渲染

  ```javascript
  import { Feature } from 'ol'
  import { Style, Fill, Stroke, Circle } from 'ol/style'
  import { Point, LineString } from 'ol/geom'
  import { fromLonLat } from "ol/proj";

  const coodLineString = [ fromLonLat([120.22, 30.26]), fromLonLat([121.22, 31.26]) ]
  const coodPonit = fromLonLat([120.22, 30.26])

  const vectorLayer = new VectorLayer({
    source: new Vector({
      features: [
        // 线
        new Feature({
          geometry: new LineString(coodLineString),
        }),

        // 点
        new Feature({
          geometry: new Point(coodPonit),
        }),
      ],
    }),
    style: new Style({
      stroke: new Stroke({
        color: '#FF0000',
        width: 2,
      }),
      fill: new Fill({
        color: '#FFFF00',
      }),

      // 设置与点相关的样式
      image: new Circle({
        radius: 7,
        fill: new Fill({ color: '#FFFF00' }),
        stroke: new Stroke({ color: '#FF0000', width: 2 }),
      }),
    }),
  })
  ```
