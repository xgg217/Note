# 常用方法

## 概述

+ Map 的方法大致可以分为图层/交互管理、坐标转换和状态查询几类

## 分类

+ 分类1 图层与交互管理

  + addLayer(layer)：在地图顶部添加图层

  + removeLayer(layer)：移除指定图层

  + addControl(control) / addInteraction(interaction)：添加控件或交互

  + addOverlay(overlay)：添加覆盖物

+ 分类2 坐标与像素转换

  + getCoordinateFromPixel(pixel)：将地图视口内的像素坐标转换为地图坐标

  + getPixelFromCoordinate(coordinate)：将地图坐标转换为视口内的像素坐标

  + getEventCoordinate(event) / getEventPixel(event)：从浏览器事件对象中直接获取坐标或像素位置

+ 分类3 要素拾取与状态查询

  + forEachFeatureAtPixel(pixel, callback, options)：检测像素下的要素并执行回调

  + hasFeatureAtPixel(pixel, options)：判断像素下是否存在要素

  + getTargetElement()：获取地图渲染的实际 DOM 元素，如果未设置 target 则返回 `null`

  + getViewport()：获取地图的视口 DOM 元素

## 动态添加或移除图层 addLayer 与 removeLayer

+ addLayer

  ```js
  const view = new View();

  const tileLayerSource = new XYZ({
    url:
      "http://t0.tianditu.gov.cn/vec_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=vec&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=" +
      import.meta.env.VITE_API_TIANDITU_MAP,
  });

  const tileLayer = new TileLayer();

  onMounted(() => {
    const map = new Map({
      target: mapRef.value!,
      layers: [],
      // view,
    });

    tileLayer.setSource(tileLayerSource);

    map.addLayer(tileLayer);

    view.setCenter([0, 0]);
    view.setZoom(4);
    map.setView(view);
  });
  ```

## 快速判断某个像素位置下是否存在要素 hasFeatureAtPixel

+ hasFeatureAtPixel 是 OpenLayers 中用于快速判断某个像素位置下是否存在要素的方法
+ 它返回一个布尔值，非常适合用于“鼠标是否悬停在要素上”这类只需判断有无的场景

+ `map.hasFeatureAtPixel(pixel, options)`

  + 参数

    + pixel `Pixel` 视口内的像素坐标，通常来自事件对象的 `e.pixel`
    + options `AtPixelOptions` （可选） 命中检测的配置项

      + layerFilter：函数，接收一个图层参数，返回 true 表示该图层参与检测，返回 false 则跳过。用于限定只在特定图层上检测要素

      + hitTolerance：数字，单位为 CSS 像素。增大该值可以扩大命中范围，让点击细小要素（如小图标、细线）更容易被拾取。默认值为

        ```js
        const hit = map.hasFeatureAtPixel(e.pixel, {
          hitTolerance: 10 // 扩大 10 像素的命中范围
        });
        ```

  + 返回值 返回布尔值，不提供要素对象，性能开销相对更小

+ 使用场景

  + 适合悬停判断、光标切换等场景

+ 示例1 基础使用：动态切换鼠标样式（当鼠标悬停在要素上时，将光标变为手型）

  ```js
  map.on('pointermove', (e) => {
    if (e.dragging) return; // 拖拽时不处理

    const hit = map.hasFeatureAtPixel(e.pixel);
    map.getTargetElement().style.cursor = hit ? 'pointer' : '';
  });
  ```

+ 示例2 配合 layerFilter 使用:如果只想检测特定图层上的要素（例如只检测名为 'selectable' 的图层），需要使用 layerFilter 选项。需要注意的是，layerFilter 的第一个参数是图层对象，而不是要素对象

  ```js
  map.on('pointermove', (e) => {
    if (e.dragging) return;

    const hit = map.hasFeatureAtPixel(e.pixel, {
      layerFilter: (layer) => layer.get('name') === 'selectable'
    });
    map.getTargetElement().style.cursor = hit ? 'pointer' : '';
  });
  ```

## 获取要素数据 forEachFeatureAtPixel

+ forEachFeatureAtPixel 是 OpenLayers 中用于像素级要素拾取的核心方法
+ 它检测屏幕上某个像素位置下有哪些要素，并对每个命中的要素执行回调

+ `map.forEachFeatureAtPixel(pixel, callback, options)`

  + 参数

    + pixel `Pixel` 视口内的像素坐标，通常来自事件对象的 e.pixel
    + callback `function(feature, layer)`

      + 回调接收两个参数：

        + feature：命中的要素对象

        + layer：该要素所在的图层

    + options `AtPixelOptions` 可选 命中检测的配置项

  + 返回值

  ```js
  // 单击
  map.on('singleclick', (e) => {
    map.forEachFeatureAtPixel(e.pixel, (feature, layer) => {
      console.log('命中的要素:', feature);
      console.log('所在图层:', layer);
      return true; // 只处理最上层的要素
    });
  });
  ```

+ 配合 hitTolerance 使用: hitTolerance 是最常用的选项，单位为CSS 像素

  + 默认值为 0，表示只检测像素正下方的要素

  + 这个参数对触摸设备尤其重要，因为手指点击很难精确命中细小的点或线
  + 设置 hitTolerance: 5 或 10 可以显著改善用户体验，让像素周围一定范围内的要素也能被拾

  ```js
  map.on('click', (e) => {
    map.forEachFeatureAtPixel(
      e.pixel,
      (feature) => {
        console.log('命中:', feature);
        return true;
      },
      { hitTolerance: 10 } // 扩大 10 像素的命中范围
    );
  });
  ```

+ 如果地图上有多个图层，只想在特定图层上拾取要素，可以使用 layerFilter

  ```js
  //  图层过滤
  map.forEachFeatureAtPixel(
    e.pixel,
    (feature) => { /* ... */ },
    {
      layerFilter: (layer) => layer === myVectorLayer // 只检测指定图层
    }
  );
  ```
