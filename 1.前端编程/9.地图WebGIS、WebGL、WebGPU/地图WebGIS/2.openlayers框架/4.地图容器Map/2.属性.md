# 属性

## target

+ 地图渲染的容器
+ 可以是 DOM 元素本身，也可以是元素的 id 字符串

  + 对应的 HTML 通常是一个具有明确宽高的 `<div>`

+ 可通过 setTarget() 修改

## view

view：控制地图视图状态（中心、缩放、投影）的 View 实例
+ 必须提供，否则地图不会加载任何图层数据
+ 可通过 `setView()` 修改

## layers

+ 地图中包含的图层集合，通常是一个 `ol.Collection`
+ 可通过 `getLayers()` 获取并操作

## controls

+ 地图控件集合，如缩放按钮、比例尺等
+ 可通过 getControls() 获取

## interactions

+ 地图交互集合，如拖拽平移、滚轮缩放等
+ 可通过 getInteractions() 获取

## overlays

+ 地图覆盖物集合，通常用于显示弹窗或标记
+ 可通过 `getOverlays()` 获取

## size

+ 地图在 DOM 中的像素尺寸，是一个 ol.Size 对象
+ 可通过 getSize() 获取

## pixelRatio

+ 地图的像素比，用于高清屏适配
+ 可通过 `getPixelRatio()` 获取
