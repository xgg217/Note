# map

## 概述

+ Map 是 OpenLayers 的核心组件，负责管理图层、视图、交互和控件，并将地图渲染到网页的指定容器中

## API 文档

+ https://openlayers.org/en/latest/apidoc/module-ol_Map-Map.html

## 必填配置

+ 一个可用的地图实例至少需要以下配置：

  + target：地图渲染的容器。可以是 DOM 元素本身，也可以是元素的 id 字符串

    + 对应的 HTML 通常是一个具有明确宽高的 `<div>`

  + view：视图，控制地图的中心点、缩放级别和投影

    + 这是必须提供的，否则地图不会加载任何图层数据

  + layers：图层数组

    + 地图需要至少一个图层（如瓦片图层）才能显示内容

## 核心配置

+ 除了上述必备项，Map 的构造函数还接受许多其他选项，常用的包括：

  + controls：初始添加的控件。如果不指定，默认会添加缩放、旋转等标准控件

  + interactions：初始添加的交互。默认包含拖拽平移、滚轮缩放等

  + overlays：初始添加的覆盖物，通常用于显示弹窗或标记。

  + renderer：渲染器类型（如 Canvas 或 WebGL）。默认会优先检测 WebGL，不可用则回退到 Canvas

## 注意点

+ 需要特别注意，中心点、缩放级别和投影不属于 Map 的属性，而是属于 View 实例的
+ 因此，你无法直接通过 `map.getZoom()` 获取缩放级别，而应该通过 `map.getView().getZoom()` 来获取

## 示例

+ 示例1

  ```html
  <script setup lang="ts">
  import Map from 'ol/Map.js';
  import View from 'ol/View.js';
  import TileLayer from 'ol/layer/Tile.js';
  import OSM from 'ol/source/OSM.js';

  const map = new Map({
    // 指定渲染容器
    target: 'map-container',

    // 配置图层（这里以 OpenStreetMap 瓦片为例）
    layers: [
      new TileLayer({
        source: new OSM()
      })
    ],

    // 配置视图（中心点和缩放级别）
    view: new View({
      center: [0, 0],
      zoom: 2
    })
  });
  </script>

  <template>
    <div id="map-container" ></div>
  </template>
  ```
