# 事件监听

## 注册与注销监听

+ OpenLayers 的 Map 对象继承自 Observable 基类，通过 on() 方法监听事件是实现地图交互的核心方式

  ```js
  // 注册监听
  const key = map.on('singleclick', (event) => {
    console.log(event.coordinate);
  });

  // 注销监听（需要用到注册时返回的 key）
  map.un('singleclick', listener, this);
  ```

+ on() 返回一个唯一的监听器标识，用于后续注销。此外还有 once() 方法，注册的监听器只触发一次后自动移除

## MapEvent 子类（基础事件）

+ movestart：地图开始移动时触发

+ moveend：地图移动结束后触发，常用于同步视图或更新状态

+ postrender：地图帧渲染完成后触发，适合做渲染后的数据处理

## MapBrowserEvent 子类（浏览器交互事件）

+ click：无拖拽的点击。双击会触发两次 click

+ singleclick：真正的单次点击。注意：此事件会延迟 250ms 触发，以确保不是双击

+ dblclick：真正的双击，无拖拽

+ pointermove：指针移动时触发。触摸设备上，地图平移时也会触发此事件

+ pointerdrag：指针拖拽时触发

## 事件对象核心属性

+ 浏览器交互事件（如 click、pointermove）携带的信息非常丰富，常用属性包括：

  + coordinate：事件对应的地图坐标，可用于在点击位置添加标记

  + pixel：事件对应的视口像素坐标，配合 forEachFeatureAtPixel 做要素拾取

  + originalEvent：原生浏览器事件对象。通过它可获取 shiftKey、ctrlKey 等修饰键状态

  + dragging：仅 pointermove/pointerdrag 时有效，表示地图是否正在被拖拽


## 示例

+ 示例1 监听点击并添加标记

  ```js
  map.on('singleclick', (event) => {
    // event.coordinate 即为点击位置的地图坐标
    addMarkerAt(event.coordinate);
  });
  ```

+ 示例2 监听移动结束以同步其他组件

  ```js
  map.on('moveend', () => {
    const center = map.getView().getCenter();
    updateSidebar(center);
  });
  ```

+ 示例3 判断修饰键 + 要素拾取

  ```js
  map.on('click', (event) => {
    if (event.originalEvent.shiftKey) {
      // 按住 Shift 键的特殊逻辑
    }
    map.forEachFeatureAtPixel(event.pixel, (feature) => {
      // 处理点击到的要素
    });
  });
  ```
