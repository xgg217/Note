# 投影坐标转换

## 概述

+ OpenLayers默认采用的是墨卡托投影坐标系，坐标单位为米
+ 如果希望使用地理坐标系（经纬度），可通过 projection 字段进行设置

  ```javascript
  new View({
    center: [120.15, 30.29],
    zoom: 2,
    projection: 'EPSG:4326' // 使用wgs84坐标系
  })
  ```

+ 如果希望采用墨卡托投影坐标系加经纬度表示的话，就需要使用投影坐标转换工具，即 `ol/proj`

  ```javascript
  import { fromLonLat, transformExtent } from 'ol/proj'

  const coordinate = fromLonLat([120.15, 30.29]); // 经纬度转墨卡托

  // 设置地图范围，使得地图只能在gai 参数 [minX, minY, maxX, maxY], 源码的坐标系，转换后的坐标系
  const extent = transformExtent([117, 26, 124, 32], 'EPSG:4326', 'EPSG:3857');

  view: new View({
    // center: [0, 0],
    center: coordinate,
    zoom: 2,
    // projection: "EPSG:4326", // 使用wgs84坐标系
    extent, // 范围（extent）的权限大于中心点（center）
  })
  ```
