# 方法

## 概述

+ View 的方法主要用于状态获取、约束设置和视角控制

## 状态获取与设置

+ getCenter() / setCenter(coordinate)：获取或设置中心点

+ getResolution() / setResolution(resolution)：获取或设置分辨率

+ getRotation() / setRotation(rotation)：获取或设置旋转角度

+ getZoom()：获取当前的缩放级别（根据分辨率计算得出）

## 视角控制

+ animate(options)：平滑地动画到新的视图状态。可以设置 center、zoom、duration（时长，毫秒）、easing（缓动函数）等参数。也支持链式动画

  ```js
  // 平滑动画到新位置
  view.animate({
    center: [200, 100],
    zoom: 8,
    duration: 2000 // 持续2秒
  });
  ```

+ fit(geometryOrExtent, options)：调整视图，使其适应给定的几何图形或范围。常用于定位到某个区域，支持 padding（内边距）、maxZoom 等选项

+ centerOn(coordinate, size, position)：将视图的中心定位到指定的坐标和像素位置

## 约束相关

+ View 的状态在设置时本身不受约束，约束只在使用交互或控件时生效

+ constrainResolution(resolution, direction)：根据约束规则，将给定分辨率调整到最接近的合法值

+ constrainRotation(rotation)：根据约束规则，调整旋转角度

+ calculateExtent(size)：根据当前视图状态和给定的像素尺寸，计算对应的地图范围（Extent）
