# 事件

## 概述

+ View 的事件类型不多，核心是三个属性变更事件，用于监听视图状态的变化

## change:center 中心点

+ 视图中心点坐标发生改变时触发
+ 例如调用 view.setCenter() 或用户拖拽地图后

  ```js
  const view = map.getView();

  // 监听中心点变化
  view.on('change:center', (event) => {
    console.log('当前中心点:', view.getCenter());
  });
  ```

## change:resolution 缩放

+ 视图分辨率发生改变时触发，即缩放级别变化
+ 例如调用 view.setZoom() 或用户滚轮缩放后

  ```js
  const view = map.getView();

  // 监听缩放变化（分辨率改变）
  view.on('change:resolution', (event) => {
    console.log('当前缩放级别:', view.getZoom());
  });
  ```

## change:rotation 旋转

+ 视图旋转角度发生改变时触发
+ 例如调用 view.setRotation() 或用户旋转地图后

  ```js
  const view = map.getView();

  // 监听旋转变化
  view.on('change:rotation', (event) => {
    console.log('当前旋转角度:', view.getRotation());
  });

  // 同时监听多个事件（共享回调）
  view.on(['change:resolution', 'change:rotation'], (event) => {
    console.log('视图状态已变化');
  });
  ```

## 同时监听多个事件

+ 共享回调

  ```js
  const view = map.getView();

  // 同时监听多个事件（共享回调）
  view.on(['change:resolution', 'change:rotation'], (event) => {
    console.log('视图状态已变化');
  });
  ```

## 与 Map 事件的区别

+ Map 的 moveend 事件在地图移动结束后触发一次；而 View 的 change:resolution 事件在缩放过程中每一帧都会触发，频率更高
+ 如果需要做性能敏感的操作（如频繁更新 UI），需留意这一点
