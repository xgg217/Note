# View

## 概述

+ View 负责管理地图的视觉状态，包括中心点、分辨率和旋转
+ 它本身不渲染任何东西，而是作为地图的“摄像机”，决定了地图的观察视角

## API 文档

+ https://openlayers.org/en/latest/apidoc/module-ol_View-View.html

## 基本使用

+ 示例

  ```js
  import {View} from 'ol';
  const map = new Map({
    view: new View({
      center: [0, 0],
      // center: coordinate,
      zoom: 4,
    })
  });
  ```

+ 示例2

  ```js
  // 创建视图
  const view = new View({
    center: [0, 0],       // 中心点坐标
    zoom: 2,              // 缩放级别
    minZoom: 1,           // 最小缩放级别
    maxZoom: 18,          // 最大缩放级别
    projection: 'EPSG:3857' // 投影（默认）
  });

  // 动态修改
  view.setCenter([100, 50]);
  view.setZoom(5);

  // 平滑动画到新位置
  view.animate({
    center: [200, 100],
    zoom: 8,
    duration: 2000 // 持续2秒
  });
  ```
