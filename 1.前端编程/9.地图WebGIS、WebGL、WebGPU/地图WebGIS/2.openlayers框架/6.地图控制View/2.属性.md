# 属性

## 概述

+ 这些是 View 最核心的状态，可以通过构造函数设置，也可以使用对应的 getter/setter 方法动态修改

+ center：视图的中心点坐标

  + 其坐标系由 projection 决定

  + 如果未设置，图层数据将不会被加载

+ resolution：视图的分辨率，单位为“投影单位/像素”（例如米/像素）

  + 它与 zoom 是互斥的，如果同时设置，zoom 会被忽略

+ rotation：视图的旋转角度，单位为弧度，正值表示顺时针旋转

  + 默认值为 0

+ projection：视图的投影。它决定了中心点的坐标系和分辨率的单位

  + 默认是 EPSG:3857（球面墨卡托）

+ zoom：一个便捷的缩放级别设置。它根据 maxZoom、zoomFactor 等参数计算出对应的分辨率

  + 如果 resolution 未设置，则必须提供 zoom 或 resolution 之一

## 示例

+ 示例1 使用设置方法

  ```js
  const view = new View();

  onMounted(() => {
    const map = new Map({
      target: mapRef.value!,
      layers: [
        new TileLayer({
          source: new XYZ({
            url:
              "http://t0.tianditu.gov.cn/vec_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=vec&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=" +
              import.meta.env.VITE_API_TIANDITU_MAP,
          }),
        }),
      ],

      // 也可以使用 map.setView(view) 方式添加到 map 对象中
      view,
    });

    // const view = new View({
    //   center: [0, 0],
    //   // center: coordinate,
    //   zoom: 4,
    // });
    view.setCenter([0, 0]);
    view.setZoom(4);
  });
  ```
