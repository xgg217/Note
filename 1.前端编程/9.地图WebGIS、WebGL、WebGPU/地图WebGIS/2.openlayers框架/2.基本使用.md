# 基本使用

## 使用

+ 下载openlayers框架

  ```shell
  npm install ol
  ```

+ map组件创建地图

  ```javascript
  import { Map, View } from 'ol'
  import { Tile as TileLayer } from 'ol/layer'
  import { OSM } from 'ol/source'

  new Map({
    target: 'map', // 对应HTML中<div>的id
    layers: [
      // 瓦片图层
      new TileLayer({
        // 数据源是 OSM
        source: new OSM() // 使用OpenStreetMap作为底图
      })
    ],
    view: new View({
      center: [0, 0],  // 地图初始中心点
      zoom: 2, // 初始缩放级别
    })
  })
  ```

+ CSS样式处理

  ```css
  /* style.css */
  @import "node_modules/ol/ol.css";
  ```
