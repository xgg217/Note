# 切换地图底图

## 概述

+ 利用setAt()、setLayers()等方法切换地图底图，也可以通过自定义样式来切换底图风格

  ```javascript
  // 矢量底图 vec_w
  // 影像底图 img_w
  // 矢量标记 cva_w
  // 影像标记 cia_w
  const baseVecLayer = new TileLayer({
    source: new XYZ({
      url: 'https://t0.tianditu.gov.cn/DataServer?T=vec_w&x={x}&y={y}&l={z}&tk=' + TDT_TOKEN
    }),
  })

  const baseImgLayer = new TileLayer({
    source: new XYZ({
      url: 'https://t0.tianditu.gov.cn/DataServer?T=img_w&x={x}&y={y}&l={z}&tk=' + TDT_TOKEN
    }),
  })

  const tagCvaLayer = new TileLayer({
    source: new XYZ({
      url: 'https://t0.tianditu.gov.cn/DataServer?T=cva_w&x={x}&y={y}&l={z}&tk=' + TDT_TOKEN
    }),
  })
  const tagCiaLayer = new TileLayer({
    source: new XYZ({
      url: 'https://t0.tianditu.gov.cn/DataServer?T=cia_w&x={x}&y={y}&l={z}&tk=' + TDT_TOKEN
    }),
  })


  map.getLayers().setAt(0, baseVecLayer)
  map.getLayers().setAt(1, tagCvaLayer)
  // or
  map.setLayers([baseVecLayer, tagCvaLayer])
  ```

  ```vue
  <template>
    <div id="map" class="nightLayer"></div>
  </template>
  <style scoped>
    .nightLayer {
      filter: grayscale(100%) invert(100%) sepia(15%) hue-rotate(180deg) saturate(1600%) brightness(70%) contrast(90%);
    }
  </style>
  ```
