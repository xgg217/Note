# 基础

## 概述

+ 交互（Interaction）是 OpenLayers 中处理用户输入的核心机制
+ 它负责将浏览器事件（鼠标、触摸、键盘）转换为地图操作，比如平移、缩放、绘制、选择等

+ 在 OpenLayers 中，`ol/interaction` 模块用于处理用户和地图之间的交互，常见交互如下：

  | **交互类**        | **功能说明**                 |
  | ----------------- | ---------------------------- |
  | `DragPan`         | 鼠标拖动画布（默认启用）     |
  | `MouseWheelZoom`  | 鼠标滚轮缩放（默认启用）     |
  | `DoubleClickZoom` | 双击缩放（默认启用）         |
  | `Draw`            | 绘制点、线、面、圆、多边形等 |
  | `Modify`          | 修改已绘制图形               |
  | `Select`          | 点击或框选地图要素           |
  | `Snap`            | 吸附（用于配合 Draw/Modify） |
  | `DragBox`         | 拉框交互（配合 Select）      |
  | `Translate`       | 拖动图形位置                 |
  | `Link`            | 坐标同步到浏览器 URL 的 hash |
  | `DragAndDrop`     | 允许用户拖拽文件到地图       |

## 启用或禁用交互

+ setActive(active) / getActive()：启用或禁用交互
+ 禁用后交互不再响应事件

  ```js
  import Draw from 'ol/interaction/Draw.js';

  const draw = new Draw({
    source: vectorSource,   // 绘制结果存入的矢量源
    type: 'Polygon'          // 绘制类型：Point、LineString、Polygon、Circle
  });

  map.addInteraction(draw);

  // 禁用绘制（比如切换到浏览模式）
  draw.setActive(false);

  // 重新启用
  draw.setActive(true);
  ```
