# Translate交互

## 概述

+ 拖动矢量要素的位置

  ```javascript
  import { Translate } from 'ol/interaction'

  map.addInteraction(
    new Translate({
      source: vectorSource,
    })
  )
  ```



  Modify交互可以修改已绘制图形。

  ```javascript
  import { Modify } from 'ol/interaction'

  // 对矢量图层添加修改交互，alt + click 可以删除顶点
  map.addInteraction(
    new Modify({
      source: vectorSource,
    })
  )
  ```
