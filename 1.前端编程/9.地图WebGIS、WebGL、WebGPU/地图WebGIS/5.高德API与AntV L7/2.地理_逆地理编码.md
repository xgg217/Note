# 地理_逆地理编码

## 概述

+ 地理编码/逆地理编码 API 是通过 HTTP/HTTPS 协议访问远程服务的接口，提供结构化地址与经纬度之间的相互转化的能力

## 地理编码

+ 地理编码是把现实世界中的地址信息（文字），转换成经纬度坐标的过程

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const address = '北京市朝阳区阜通东大街6号'
  const url = `https://restapi.amap.com/v3/geocode/geo?key=${GD_TOKEN}&address=${address}`
  fetch(url)
    .then(response => response.json())
    .then(data => {
      console.log('Geocode data:', data)
    })
    .catch(error => {
      console.error('Fetch error:', error)
    })
  ```

  function getJSON(url, fn) {

  }

## 逆地理编码

+ 逆地理编码则是反过来：把经纬度坐标转换成人类可读的地址

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const location = '116.310003,39.991957'
  const url = `https://restapi.amap.com/v3/geocode/regeo?key=${GD_TOKEN}&location=${location}`
  fetch(url)
    .then(response => response.json())
    .then(data => {
      console.log('Geocode data:', data)
    })
    .catch(error => {
      console.error('Fetch error:', error)
    })
  ```

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const location = '116.310003,39.991957'
  const url = `https://restapi.amap.com/v3/geocode/regeo?key=${GD_TOKEN}&location=${location}&poitype=080302&extensions=all&radius=10000`
  fetch(url)
    .then(response => response.json())
    .then(data => {
      console.log('Geocode data:', data)
    })
    .catch(error => {
      console.error('Fetch error:', error)
    })
  ```
