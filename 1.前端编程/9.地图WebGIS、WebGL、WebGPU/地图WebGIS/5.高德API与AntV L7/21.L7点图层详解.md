# L7点图层详解

## 概述

+ 在 L7 中，**点图层（PointLayer）** 是最常用的一种图层类型，用于在地图上绘制散点数据，例如 POI、站点、事件坐标等。它能通过不同的视觉通道（颜色、大小、形状、透明度等）来表达数据的属性特征

  ```javascript
  import tentea from './assets/tentea.json'

  const pointLayer = new PointLayer()
    .source(tentea)
    .shape('circle') // 'circle' | 'square' | 'triangle' | 'hexagon' | 'pentagon' | 'octogon' | 自定义属性
    .color('#FF0000')
    .size(50)
    .style({
      opacity: 0.5,
      strokeWidth: 1,
      stroke: '#FF0000',
    })
    .active(true)

  scene.addLayer(pointLayer)
  ```

  ```javascript
  // 动画：水波、雷达
  const pointLayer = new PointLayer()
    .source(tentea)
    .shape('circle')   // radar
    .animate(true)
  ```

  ```javascript
  // 简单点
  const pointLayer = new PointLayer()
    .source(tentea)
    .shape('simple')   // 面向相机
  ```
