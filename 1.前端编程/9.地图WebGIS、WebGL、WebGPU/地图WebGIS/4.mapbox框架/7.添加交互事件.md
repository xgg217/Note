# 添加交互事件

## 概述

+ 在 Mapbox 里添加交互事件，本质上是通过 `map.on()` 给图层绑定鼠标或触摸事件

  ```javascript
  map.on('click', (e) => {
    console.log(e.lngLat)
  })

  map.on('click', 'layer_hz', (e) => {

    console.log(e.features[0].properties.name)

    map.flyTo({
      center: e.lngLat,
      zoom: 10,
    })

  })
  ```
