# 初始渲染与离线访问

## 概述

+ Mapbox 是一个提供 Web 和移动端交互式地图服务的平台，  主要由 Mapbox GL JS（ Mapbox 的核心前端 JS 库，基于 WebGL 渲染地图 ）和 Mapbox API 和服务 （ 提供矢量瓦片、地理编码（Geocoding）、路线规划（Directions）、热力图（Heatmap）、地理空间分析等服务  ）组成

+ 官网地址：[https://www.mapbox.com/](https://www.mapbox.com/)

+ 文档地址：[https://docs.mapbox.com/](https://docs.mapbox.com/)

Mapbox的使用，需要申请token，这样可以使用内置的底图、字体、3D资源等

  ```javascript
  mapboxgl.accessToken = 'YOUR_MAPBOX_ACCESS_TOKEN'
  const map = new mapboxgl.Map({
    container: 'map',
    style: 'mapbox://styles/mapbox/standard',
    zoom: 4,
    center: [30, 15],
  })
  ```

## 初始化

+ 用Vite + Vue创建工程

  ```shell
  npm create vite@latest
  ```

+ 下载 Mapbox GL JS 框架

  ```shell
  npm install mapbox-gl
  ```

### 离线访问

+ 跳过token的权限限制，对源码进行修改，如下：

  ![](https://duyi-resource.oss-cn-beijing.aliyuncs.com/dupeng/1755069928295-2f73aec2-5107-4d57-870c-2a87b3bdba24.png)

+ 删除.vite缓存，重启vite

+ 初始地图代码，如下：

  ```javascript
  import mapboxgl from 'mapbox-gl'
  import 'mapbox-gl/dist/mapbox-gl.css'

  const TDT_TOKEN = '55c0066c8dd3630394c756dfcd97add5'

  new mapboxgl.Map({
    container: 'map',
    center: [120.15, 30.29],
    zoom: 4,
    style: {
      version: 8,  // 版本,一般都是8
      glyphs: './assets/lib/{fontstack}/{range}.pbf',  // 字体文件，可以自己去切片
      sources: {    // 数据源,必须是一个对象
        tdt_vec: {
          id: 'source_vec',
          type: 'raster',
          tiles: [
            `http://t0.tianditu.gov.cn/vec_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=vec&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`,
          ],
          tileSize: 256,
        },
        tdt_cva: {
          id: 'source_cva',
          type: 'raster',
          tiles: [
            `http://t0.tianditu.gov.cn/cva_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=cva&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`,
          ],
          tileSize: 256,
        },
      },
      layers: [    // 图层，必须是一个数组
        {
          id: 'layer_vec',
          type: 'raster',
          source: 'tdt_vec',
          layout: {},
          paint: {},
        },
        {
          id: 'layer_cva',
          type: 'raster',
          source: 'tdt_cva',
          layout: {},
          paint: {},
        },
      ],
    },
  })
  ```
