# 地理概念

## 概述

+ 地图底图（Basemap）是地图应用中的**基础背景图层**，用于提供地理空间参考和视觉背景，帮助用户理解地理要素的空间位置

## 开放地图

+ 开放地图是指一种对公众开放、自由使用、自由获取、自由分享和自由编辑的地图数据系统+ [OpenStreetMap](https://www.openstreetmap.org/) (OSM)   全球最大开源地图项目，可自由编辑、下载和使用

+ 国内可以使用[天地图](https://www.tianditu.gov.cn/)作为地图底图，目前是免费使用，但是有限额次数，需要申请权限token才能使用

+ 步骤：注册登录 -> 开发资源 -> 控制台 -> 创建新应用 -> 获取token

## 商业地图

+ Google Map
+ 百度地图
+ 高德地图

+ 开发者阶段可以免费使用， 使用过程中都需要申请权限token
+ 正式对外发布时需获得商用许可授权，授权一般需要按年进行付费
