# 配置文件

## 概述

+ Vitest 的配置可以放在 `vitest.config.ts`（或 `.js`）中，也可以复用现有的 `vite.config.ts` 文件

+ 配置文件格式：支持 .ts, .js, .mts, .cjs 等常见格式，但不支持 json

+ 参考文档 `https://cn.vitest.dev/config/`

## 优先级

+ 如果同时存在 `vitest.config.ts` 的优先级高于 `vite.config.ts` 后者会被忽略

## 与 Vite 的关系

+ Vitest 基于 Vite，因此配置文件中的顶级字段（如 resolve.alias 定义路径别名）对两者都生效，而测试专属配置必须放在 test 属性下


## 示例

+ 一个同时包含 Vite 插件和 Vitest 测试配置的文件通常长这样：

  ```ts
  // vitest.config.ts
  import { defineConfig } from 'vitest/config';
  import vue from '@vitejs/plugin-vue'; // 举例：Vue 插件
  import path from 'path';

  export default defineConfig({
    // Vite 配置（顶层）
    plugins: [vue()],
    resolve: {
      alias: {
        '@components': path.resolve(__dirname, 'src/components'),
      }
    },
    // Vitest 配置（在 test 属性下）
    test: {
      globals: true,
      environment: 'happy-dom',
      setupFiles: ['./test/setup.ts'],
      coverage: {
        provider: 'v8',
        reporter: ['text', 'html'],
      },
    },
  });
  ```
