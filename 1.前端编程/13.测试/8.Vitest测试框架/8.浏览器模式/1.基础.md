## 配置

+ 想要在 Vitest 中启用浏览器模式，只需在配置文件中将 `browser.enabled` 设置为 `true`

  ```js
  // vitest.config.ts
  import { defineConfig } from 'vitest/config'
  import { playwright } from '@vitest/browser-playwright'

  export default defineConfig({
    test: {
      browser: {
        provider: playwright(),
        enabled: true,
        // 至少需要一个实例
        instances: [
          { browser: 'chromium' },
        ],
      },
    }
  })
  ```

+ Vitest 默认分配端口号 63315 以避免与开发服务器冲突，允许我们同时并行运行两者。我们可以通过 api 选项来更改这个端口号
