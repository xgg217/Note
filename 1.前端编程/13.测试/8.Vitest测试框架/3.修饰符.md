# 修饰符

## 概述

+ 在 Vitest 中，修饰符（Modifiers） 是指可以链式接在 expect 或匹配器之后，用来修改断言行为的辅助方法
+ 它们让你的断言更加灵活和精确

## .not 取反断言

+ .not 它会对紧随其后的匹配器结果取反

  ```js
  test('.not 基础用法', () => {
    expect(1).not.toBe(2)              // 1 不等于 2，通过
    expect({ a: 1 }).not.toEqual({ b: 1 }) // 对象不相等，通过
    expect('hello').not.toMatch(/^world/)  // 不以 world 开头，通过
  })
  ```

## .resolves 异步成功断言

+ .resolves 用于等待一个 Promise 成功（resolve），然后对其成功值进行断言。必须使用 `await`

  ```js
  import { describe, it, expect } from 'vitest'

  const fetchData = () => Promise.resolve({ name: 'John', age: 30 })

  it('.resolves 用法', async () => {
    // 方式一：直接在 expect 中使用 resolves
    await expect(fetchData()).resolves.toMatchObject({ name: 'John' })

    // 方式二：与 .not 组合
    await expect(fetchData()).resolves.not.toHaveProperty('email')
  })
  ```

+ 注意点

  ```js
  // ❌ 忘记 await：断言可能不会执行，测试误报通过
  expect(fetchData()).resolves.toBe('ok')

  // ✅ 正确写法
  await expect(fetchData()).resolves.toBe('ok')
  ```

## .rejects 异步失败断言

+ .rejects 用于等待一个 Promise 失败（reject），然后对其错误信息或错误对象进行断言。同样必须使用 await

  ```js
  const throwError = () => Promise.reject(new Error('网络超时'))

  it('.rejects 用法', async () => {
    // 基础用法：检查是否 reject
    await expect(throwError()).rejects.toThrow()

    // 检查具体的错误消息
    await expect(throwError()).rejects.toThrow('网络超时')

    // 检查错误类型
    await expect(throwError()).rejects.toThrow(Error)

    // 配合 .not 使用
    await expect(throwError()).rejects.not.toThrow('成功')
  })
  ```
