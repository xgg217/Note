# 模拟模块

## 概述

+ 模拟模块（Mocking Modules） 是指用测试替身（Test Double）来替换项目中整个模块的导出
+ 这比单独模拟一个函数更强大，适合替换包含多个函数、类或常量的复杂依赖，例如 API 客户端、工具库或第三方服务

## 分类

+ 第三方模块
+ 文件模块

## 分类1 模拟第三方模块

+ 模拟

  ```js
  // 实际请求
  axios.get("/users.json").then((resp) => resp.data);
  ```

+ 方式1

  ```js
  const userData = require("./user.json");
  const axios = require('axios');
  const User = require('../api/userApi');

  // 模拟 axios 模块
  jest.mock('axios');

  // 测试用例
  test("测试获取用户数据", async ()=>{
    // 模拟响应数据
    const resp = {
        data : userData
    };
    // 现在我们已经模拟了 axios
    // 但是目前的 axios 没有书写任何的行为
    // 因此我们需要在这里进行一个 axios 模块行为的指定
    // 指定了在使用 axios.get 的时候返回 resp 响应
    axios.get.mockImplementation(()=>Promise.resolve(resp));

    await expect(User.all()).resolves.toEqual(userData);
  });
  ```

+ 方式2：可以传入第二个参数，第二个参数可以指定模块的一些实现

  ```js
  // const axios = require("axios");
  const User = require("../api/userApi");
  const userData = require("./user.json");

  // 模拟 axios 模块
  jest.mock("axios", () => {
    const userData = require("./user.json");
    // 模拟响应数据
    const resp = {
      data: userData,
    };
    return {
      get: jest.fn(() => Promise.resolve(resp)),
    };
  });

  // 测试用例
  test("测试获取用户数据", async () => {
    // 现在我们已经模拟了 axios
    // 但是目前的 axios 没有书写任何的行为
    // 因此我们需要在这里进行一个 axios 模块行为的指定
    // 指定了在使用 axios.get 的时候返回 resp 响应
    // axios.get.mockImplementation(()=>Promise.resolve(resp));

    await expect(User.all()).resolves.toEqual(userData);
  });

  ```
