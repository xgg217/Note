## Expect.Soft 软性断言

+ 使用 `expect.soft()` 可以在一个测试中收集多个断言失败，而不会在第一个失败时中断执行

  ```js
  test('软断言示例', () => {
    expect.soft(1 + 1).toBe(3)  // 失败，但继续执行
    expect.soft(2 + 2).toBe(5)  // 失败，继续执行
    // 测试结束后统一报告所有失败
  })
  ```

## expect.assertions 断言不执行

+ 用于确保异步代码中的断言真的被执行了，防止测试误报通过

  ```js
  test('确保断言被调用', async () => {
    expect.assertions(1)  // 必须执行 1 次断言
    await someAsyncFunction()
    expect(true).toBe(true)
  })
  ```

## 自定义断言消息

+ expect 支持添加第二个参数作为自定义错误消息，便于调试

  ```js
  expect(2 + 2).toBe(5, '2+2 应该等于 4，但实际不是')
  // 失败时会输出：2+2 应该等于 4，但实际不是
  ```
