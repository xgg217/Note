# 非对称匹配器

## 非对称匹配器 与 普通匹配器 的区别

+ 普通匹配器：`expect(actual).toBe(expected)` —— 用实际值去匹配期望值

  ```js
  const stu = {name : "张三", score : {html : 100, css : 90}};
  expect(stu).not.toBe({name : "张三", score : {html : 100, css : 90}});
  ```

+ 非对称匹配器：`expect(actual).toEqual(expect.any(Number))` —— 用期望模板去匹配实际值，不关心具体值，只关心类型、结构或是否满足某个条件

  ```js
  const arr = ["张三"];
  test("上面的数组不包含某一项", () => {
    // expect.not.arrayContaining(arr) 期望不包含数组 arr
    expect(["李四", "王五", "赵六"]).toEqual(expect.not.arrayContaining(arr));
  });
  ```

+ 非对称匹配器是放在 `expect()` 括号里的特殊占位符，用来模糊匹配实际值，非常适合用于对象、数组或 API 响应等复杂结构的断言


## expect.any(constructor)

+ 匹配任何由指定构造函数创建的值（包括基本类型和对象）

  ```js
  // 基本类型
  expect(123).toEqual(expect.any(Number))
  expect('hello').toEqual(expect.any(String))
  expect(true).toEqual(expect.any(Boolean))
  ```

  ```js
  // 对象/数组
  expect([]).toEqual(expect.any(Array))
  expect({}).toEqual(expect.any(Object))
  expect(new Date()).toEqual(expect.any(Date));

  // 在对象属性中使用
  const user = { id: 1, name: 'Alice', createdAt: new Date() }
  expect(user).toEqual({
    id: expect.any(Number),
    name: expect.any(String),
    createdAt: expect.any(Date)
  })
  ```

## expect.anything()

+ 匹配除 `null` 和 `undefined` 之外的任何值
+ 通常用于你只关心属性存在，但不关心具体值是什么的场景

  ```js
  expect(1).toEqual(expect.anything())
  expect('test').toEqual(expect.anything())
  expect([]).toEqual(expect.anything())
  expect({}).toEqual(expect.anything())

  // ❌ 以下会失败
  expect(null).not.toEqual(expect.anything())
  expect(undefined).not.toEqual(expect.anything())

  // 在对象中使用
  const response = { status: 200, data: { id: 42, name: 'Bob' } }
  expect(response).toEqual({
    status: expect.anything(), // 任何非空值都可以
    data: expect.any(Object)
  })
  ```

## expect.arrayContaining(array)

+ 匹配一个数组，它包含了期望数组中的所有元素（顺序无关）
+ 适合用于验证数组包含关键元素，而忽略其他额外元素

  ```js
  const actual = [1, 2, 3, 4, 5]

  expect(actual).toEqual(expect.arrayContaining([2, 4]))
  expect(actual).toEqual(expect.arrayContaining([1, 3, 5]))
  expect(actual).not.toEqual(expect.arrayContaining([10])) // 不包含 10

  // 可以嵌套其他非对称匹配器
  const users = [
    { id: 1, name: 'Alice' },
    { id: 2, name: 'Bob' },
    { id: 3, name: 'Charlie' }
  ]
  expect(users).toEqual(
    expect.arrayContaining([
      expect.objectContaining({ id: 2 }),
      expect.objectContaining({ name: 'Charlie' })
    ])
  )
  ```

  ```js
  nst arr = ["张三"];

  // 匹配不含 张三 的数组
  expect(["李四", "王五", "赵六"]).toEqual(expect.not.arrayContaining(arr));
  ```

## expect.objectContaining(object)

+ 匹配一个对象，它包含了期望对象中的所有属性（可以有额外属性）
+ 是最常用的非对称匹配器之一

  ```js
  const user = { id: 1, name: 'Alice', email: 'alice@test.com', role: 'admin' }

  expect(user).toEqual(expect.objectContaining({
    id: 1,
    name: 'Alice'
  }))

  // 配合 expect.any 使用
  expect(user).toEqual(expect.objectContaining({
    id: expect.any(Number),
    email: expect.stringContaining('@')
  }))

  // 嵌套使用
  const complex = {
    user: { id: 1, profile: { age: 25, city: '深圳' } },
    status: 'active'
  }
  expect(complex).toEqual(
    expect.objectContaining({
      user: expect.objectContaining({
        profile: expect.objectContaining({ city: '深圳' })
      })
    })
  )
  ```

## expect.stringContaining(string)

+ 匹配一个包含特定子串的字符串

  ```js
  expect('hello world').toEqual(expect.stringContaining('world'))
  expect('hello world').toEqual(expect.stringContaining('hello'))
  expect('hello world').not.toEqual(expect.stringContaining('xyz'))

  // 在对象中使用
  const response = { message: '操作成功：用户已创建' }
  expect(response).toEqual({
    message: expect.stringContaining('成功')
  })
  ```

## expect.stringMatching(regexp)

+ 匹配一个符合正则表达式的字符串
+ 比 `stringContaining` 更强大灵活

  ```js
  expect('hello123').toEqual(expect.stringMatching(/^[a-z]+\d+$/))
  expect('test@example.com').toEqual(expect.stringMatching(/@/))
  expect('2026-07-22').toEqual(expect.stringMatching(/\d{4}-\d{2}-\d{2}/))

  // 在对象中使用
  const user = { id: 'USER_001', email: 'test@mail.com' }
  expect(user).toEqual({
    id: expect.stringMatching(/^USER_\d{3}$/),
    email: expect.stringMatching(/^[^@]+@[^@]+\.[^@]+$/)
  })
  ```

## expect.closeTo(num, digits?)

+ 匹配一个近似等于某个数的浮点数（解决精度问题）。digits 参数指定小数点后几位精度，默认 2 位

  ```js
  expect(0.1 + 0.2).toEqual(expect.closeTo(0.3, 5))    // 0.30000000000000004 ≈ 0.3

  // 普通用法
  expect(1.23456).toEqual(expect.closeTo(1.23, 2))     // 1.23 精度
  expect(1.23456).not.toEqual(expect.closeTo(1.24, 2)) // 四舍五入后不等

  // 在对象中使用
  const stats = { total: 99.999, average: 33.333 }
  expect(stats).toEqual({
    total: expect.closeTo(100, 0),    // 100.0 精度 0 位
    average: expect.closeTo(33.33, 2) // 33.33 精度 2 位
  })
  ```
