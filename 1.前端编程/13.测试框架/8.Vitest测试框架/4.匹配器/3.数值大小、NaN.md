# 数值大小

## toBeGreaterThan 大于

+ 大于

  ```js
  expect(10).toBeGreaterThan(5)
  ```

## toBeGreaterThanOrEqual 大于等于

+ 大于等于

  ```js
  expect(10).toBeGreaterThanOrEqual(10)
  ```

## toBeLessThan 小于

+ 小于

  ```js
  expect(5).toBeLessThan(10)
  ```

## toBeLessThanOrEqual 小于等于

+ 小于等于

  ```js
  expect(5).toBeLessThanOrEqual(5)
  ```

## toBeCloseTo 近似相等

+ 浮点数近似相等（避免精度问题） `(value: number, numDigits?: number) => Awaitable<void>`

  + numDigits ： 小数点位数，默认 2位，比较小数点后面的是否相等

  ```js
  expect(0.302).toBe(0.301); // true 默认比较小数点后 2位
  expect(0.302).toBe(0.301, 5); // false 默认比较小数点后 2位

  expect(0.2 + 0.1).toBe(0.3) // false 0.2 + 0.1 is 0.30000000000000004

  expect(0.1 + 0.2).toBeCloseTo(0.3, 5)
  ```

## toBeNaN 匹配 NaN

+ 匹配 `NaN`

  ```js
  expect(NaN).toBeNaN()
  ```
