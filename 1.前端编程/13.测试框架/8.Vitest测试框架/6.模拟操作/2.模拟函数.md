# 模拟函数

## 创建模拟函数的三种方式

+ `vi.fn(implementation?)` 创建空白模拟函数
+ `vi.fn().mockImplementation(fn)` —— 带实现的模拟函数
+ 从现有函数创建模拟函数

## 方式1 vi.fn(implementation?) 创建空白模拟函数

+ 创建空白模拟函数

  ```js
  import { expect, test, vi } from "vitest";

  test("模拟函数", () => {
    // 创建一个模拟函数
    const mock = vi.fn();

    // 设置这个模拟函数的返回值为 42
    mock.mockReturnValue(42);

    expect(mock()).toBe(42);
  });
  ```

## 方式2 vi.fn().mockImplementation(fn) 带实现的模拟函数

+ 传入一个函数来代表模拟函数的实现

  ```js
  // 方式一：直接在 vi.fn() 中传入实现
  const add = vi.fn((a, b) => a + b)
  expect(add(1, 2)).toBe(3)

  // 方式二：链式调用 mockImplementation
  const multiply = vi.fn().mockImplementation((a, b) => a * b)
  expect(multiply(2, 3)).toBe(6)
  ```

## 方式3 从现有函数创建模拟函数

+ 从现有函数创建模拟函数

  ```js
  import { sum } from './math'

  // 用 vi.fn() 包装真实函数，自动追踪调用
  const mockSum = vi.fn(sum)
  mockSum(1, 2) // 内部执行真实的 sum 逻辑

  expect(mockSum).toHaveBeenCalledWith(1, 2)
  expect(mockSum(3, 4)).toBe(7) // 仍然返回真实计算结果
  ```
