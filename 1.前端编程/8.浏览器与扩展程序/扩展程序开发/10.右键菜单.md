# 右键菜单

## 概述

+ 使用 chrome.contextMenus API 可向 Google Chrome 的上下文菜单添加项。您可以选择上下文菜单添加项所适用的对象类型，例如图片、超链接和网页

## 权限

+ contextMenus

+ 您必须在扩展程序的清单中声明 "contextMenus" 权限，才能使用该 API。此外，您还应指定一个 16x16 像素的图标，以便在菜单项旁边显示

  ```json
  {
    "name": "My extension",
    ...
    "permissions": [
      "contextMenus"
    ],
    "icons": {
      "16": "icon-bitty.png",
      "48": "icon-small.png",
      "128": "icon-large.png"
    },
    ...
  }
  ```
