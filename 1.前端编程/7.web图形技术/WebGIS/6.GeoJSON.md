# GeoJSON

## 概述

+ GeoJSON 是一种基于 JSON 的地理空间数据格式，可以是 .json 文件或 .geojson 文件，用于表示地理特征（如点、线、多边形）以及它们的属性信息
+ 它被广泛用于 WebGIS（如 OpenLayers、Leaflet、Mapbox）中进行地图数据展示和交互

+ GeoJSON编码格式：[https://geojson.org/](https://geojson.org/)

  + feature：要素（点，线，面等）
  + properties：属性集合（可以自定义）
  + geometry：要素的图形信息（图形类别、坐标数据）

  ```json
  {
    "type": "Feature",
    "geometry": {
      "type": "Point",
      "coordinates": [125.6, 10.1]
    },
    "properties": {
      "name": "Dinagat Islands"
    }
  }
  ```



## geometry图形

  | **geometry（图形）** | **type（类别）** | **coordinates（坐标）** |
  | --- | --- | --- |
  | 点 | Point | [119, 30] |
  | 多点 | MultiPoint | [<br />[119, 30],  [120, 31], ...<br/>] |
  | 线 | LineString | [<br/>[119, 30],  [120, 31], ...<br/>] |
  | 多线 | MultiLineString | [<br/>[<br/>[119, 30],  [120, 31], ...<br/>],<br/>[<br/>[121, 32],  [122, 33], ...<br/>]<br/>] |
  | 面 | Polygon | [<br/>[<br/>[119, 30],  [120, 31], ...<br/>]<br/>] |
  | 多面 | MultiPolygon | [<br/>[<br/>[119, 30],  [120, 31], ...<br/>],<br/>[<br/>[121, 32],  [122, 33], ...<br/>]<br/>] |

+ GeoJSON有时候会一次性表示多个要素：

  ```json
  {
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "name": "宁波市" },
      "geometry": {
        "type": "Point",
        "coordinates": [120.3422342, 29.23423]
      }
    },
    {
      "type": "Feature",
      "properties": { "name": "杭州市" },
      "geometry": {
        "type": "Point",
        "coordinates": [120.3422342, 29.23423]
      }
    }
  ]
  }
  ```
