# GIS数据

## 概述

+ GIS数据大致可以分为两类，专业的名称叫做

  + 栅格数据
  + 矢量数据

## 栅格数据

+ 栅格数据（raster data）也叫遥感影像数据， 来源包括卫星、航天飞机、无人机等。典型格式为 `.tif`，该格式支持嵌入经纬度坐标信息，可直接加载到地图中

+ 其他图像格式如 `.png`、`.jpg` 等**不包含地理坐标信息**，需手动在代码中补充信息后才能用于地图展示。

![](https://duyi-resource.oss-cn-beijing.aliyuncs.com/dupeng/1752979893278-81f31944-bac3-4a06-b88d-32bba4bc2381.png)

  ```javascript
  import image from './assets/xc.png'
  const extent = [
    ...fromLonLat([101.73497559, 27.50030558]),
    ...fromLonLat([102.43557243, 28.18097996])
  ]
  new Map({
    target: 'map',
    layers: [
      new ImageLayer({
        source: new Static({
          url: image,
          projection: get('EPSG:3857'),
          imageExtent: extent,
        }),
      }),
    ],
    view: new View({
      center: getCenter(extent),
      zoom: 10,
    })
  })
  ```

## 矢量数据

+ 矢量数据（vector data）用于描述地理对象的形状、位置和属性，来源包括：

  + **测绘数据**：由经纬度测量仪器采集，记录地块边界、面积等信息。
  + **人工提取数据**：通过遥感影像提取生成的地理实体，如居民区、道路、河流等。



+ 常用的矢量数据格式包括：

  | **格式** | **简介** |
  | --- | --- |
  | `.shp` | Shapefile，传统格式，支持属性表 |
  | `.geojson` / `.json` | 基于 JSON 的轻量地理格式，广泛用于 WebGIS |
  | `.kml` | Google Earth 使用的标记语言 |
  | `.gml` | 地理标记语言，基于 XML |
  | `.wkt` | 文本表示的几何对象 |

## 总结

+ 栅格数据，即图像；矢量数据，即图形。 栅格数据的优点在于能够精准而真实的展示地物的样貌，最真实的还原地球表面的状态
+ 所以通常一些影像图能够作为底图。栅格数据的缺点在 于可编辑性可交互性差，通常你不能对一张图片进行什么高端的操作（点击高亮，下钻，展示属性等等）。矢量数据的优点正好就是栅格数据的缺点，你可以对矢量数据进行交互操作
