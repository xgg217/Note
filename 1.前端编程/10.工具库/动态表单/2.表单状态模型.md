# 表单状态模型

## 为什么需要 OOP 模型？

+ 真实表单中，每个字段还需要

  ```
  value	当前值
  visible	是否可见
  touched	是否被用户操作过
  dirty	是否已修改（与初始值不同）
  errors	校验错误列表
  validating	是否正在异步校验
  ```

+ 如果全部塞进一个扁平对象里，代码会变得非常混乱。所以我们用 面向对象 的方式，给每个字段创建一个 Field 实例

## Field 类（基础版）

+ `src/form/field.ts`

+ 每个 Field 持有对 Form 的引用（this.form），这样 Field 可以拿到其他字段的值（通过 this.form.values），这为后续的联动和校验打下基础

  ```js
  import type { Form } from "./form";

  export class Field {
    // 字段名称（字段的唯一标识）
    name: string;
    // 当前值
    value: any;
    // 初始值
    initialValue: any;
    // 是否显示该字段
    visible: boolean = true;

    // 用户是都操作过该字段
    // (主要是为了验证的时候避免页面打开就报错)
    touched = false;

    // 当前值是都不同于初始值
    // 主要是为了 判断是否需要提交，高亮修改过的字段等
    dirty = false;

    // 校验错误列表
    error: string[] = [];

    // 是否正在进行一步校验
    // 比如loading状态(显示“校验中...”)
    validating = false;

    form: Form;

    constructor(name: string, form: Form, initialValue: any = "") {
      this.name = name;
      this.form = form;
      this.value = initialValue;
      this.initialValue = initialValue;
    }

    setValue(value: any) {
      this.value = value;
      this.dirty = this.value !== this.initialValue;
      this.touched = true;
    }

    reset() {
      this.value = this.initialValue;
      this.dirty = false;
      this.touched = false;
      this.error = [];
      this.validating = false;
    }

  }
  ```

## Form 类（基础版）

+ `src/form/form.ts`

  ```js
  // form/form.ts
  import { Field } from "./field";

  export class Form {
    fields: Record<string, Field> = {};

    registerField(name: string, initialValue?: any) {
      const field = new Field(name, this, initialValue);
      this.fields[name] = field;
      return field;
    }

    get values() {
      const result: Record<string, any> = {};
      Object.keys(this.fields).forEach((name) => {
        result[name] = this.fields[name].value;
      });
      return result;
    }

    reset() {
      Object.values(this.fields).forEach((field) => {
        field.reset();
      });
    }
  }
  ```

## createForm 工厂函数

+ `src/form/createForm.ts`

  ```js
  // form/createForm.ts
  import { Form } from "./form";
  import type { FieldSchema } from "../schema";

  export function createForm(schema: FieldSchema[]) {
    const form = new Form();

    schema.forEach((item) => {
      form.registerField(item.name, item.initialValue);
    });

    return form;
  }
  ```
