# 基础

## 概述

+ 前端主题切换，其实就是切换 CSS

+ CSS 中变换最大的就是

  + 颜色相关的属性
  + 图片
  + icon

## 样式切换的解决方案

+ 方式1: CSS 变量 + CSS 样式 data-set

  + 缺点：如果变换的内容比较多，可能会出现白屏的情况

  ```css
  :root {
    --vt-c-bhc: #fff;
  }

  .dark {
    --vt-c-bhc: #000;
  }

  /*
    可能使用JS，点击某个按钮之后，切换根元素的CSS样式
    样式切换之后，意味着 CSS 变量的值也改变了
   */
  .layer {
    backround-color: var(--vt-c-bg);
  }
  ```

+ 方式2: CSS 预处理器（SCSS、less） + CSS 样式 data-set

  + 原理：使用预处理器就是先把所有的主题样式涉及到的内容全部写好，当切换的时候直接就切换了
  + 缺点：刚开始加载的时候会有白屏

  ```css
  /*  */
  html.primary .layer {
    color: #fff;
  }

  html.dark .layer {
    color: #000;
  }
  ```
