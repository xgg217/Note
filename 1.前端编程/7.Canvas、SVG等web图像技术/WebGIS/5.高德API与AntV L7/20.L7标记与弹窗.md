# L7标记与弹窗

## 概述

+ 在 L7 中，可通过 Marker 、Popup 实现点标记与信息弹窗

  ```javascript
  import { Scene, Marker, Popup } from '@antv/l7'
  import tentea from './assets/tentea.json'

  tentea.features.forEach((f) => {
    const marker = new Marker({
    }).setLnglat({ lng: f.geometry.coordinates[0], lat: f.geometry.coordinates[1] })
    scene.addMarker(marker)

    const popup = new Popup({
      offsets: [0, 50],
      closeButton: true,
      closeOnClick: true,
    }).setHTML(`
      <div>
        <h3>${f.properties.name}</h3>
      </div>
    `)
    marker.setPopup(popup)
  })
  ```
