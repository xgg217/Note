# L7地理可视化

## 概述

+ L7 是由蚂蚁金服 AntV 数据可视化团队推出的基于 WebGL 的开源大规模地理空间数据可视分析开发框架
+ L7 中的 L 代表 Location，7 代表世界七大洲，寓意能为全球位置数据提供可视分析的能力
+ L7 以图形符号学为理论基础，将抽象复杂的空间数据转化成 2D、3D 符号，通过颜色、大小、体积、纹理等视觉变量实现丰富的可视化表达

## AntV L7 与 AMap JS API 2.0 对比

+ AMap：主要功能**地图服务**、业务接口，适合出行、物流、导航类应用开发
+ L7：专注于空间**数据可视化**，不提供地图服务本身，适合大屏数据分析等应用

+ 官方文档：[https://l7.antv.antgroup.com/](https://l7.antv.antgroup.com/)

## L7 初始化

+ 下载相关模块

  ```shell
  npm install @antv/l7 @antv/l7-maps
  ```



  ```javascript
  import { onMounted } from 'vue'
  import { Scene } from '@antv/l7'
  import { GaodeMap } from '@antv/l7-maps'

  window._AMapSecurityConfig = {
    securityJsCode: '41666af21c674a347f2f5ccb2376a9be',
  }
  const GD_TOKEN = 'e80ed49a1861eea77f72f826ec23f8af'

  onMounted(() => {
    new Scene({
      id: 'map',
      map: new GaodeMap({
        style: 'darkblue',
        center: [120.15, 30.29],
        zoom: 5,
        token: GD_TOKEN,
      }),
    })
  })
  ```

  import { onMounted } from 'vue'
