# 静态图片

## 概述

+ 静态地图服务通过返回一张地图图片响应 HTTP 请求，使用户能够将高德地图以图片形式嵌入自己的网页中。用户可以指定请求的地图位置、图片大小、以及在地图上添加覆盖物，如标签、标注、折线、多边形

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const zoom = '10'
  const location = '116.310003,39.991957'
  const markers = `mid,0xFF0000,A:${location}`
  const src = `https://restapi.amap.com/v3/staticmap?key=${GD_TOKEN}&zoom=${zoom}&location=${location}&markers=${markers}`
  ```
