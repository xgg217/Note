# 07. 天气查询

### 概述

+ 天气查询是一个简单的 HTTP 接口，根据用户输入的 adcode，查询目标区域当前/未来的天气情况

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const city = '330100'
  const url = `https://restapi.amap.com/v3/weather/weatherInfo?key=${GD_TOKEN}&city=${city}`

  fetch(url)
    .then(response => response.json())
    .then(data => {
      console.log('Geocode data:', data)
    })
    .catch(error => {
      console.error('Fetch error:', error)
    })
  ```

