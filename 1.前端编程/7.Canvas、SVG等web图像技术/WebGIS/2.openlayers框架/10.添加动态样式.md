# 添加动态样式

## 概述

+ 如果希望根据GeoJSON的自定义数据动态控制样式变化，可以给图层的style字段设置函数写法

  ```javascript
  import { Style, Fill, Stroke, Text } from 'ol/style'

  const vectorLayer = new VectorLayer({
    source: vectorSource,
    style: (feature) => {
      const name = feature.get('name')
      return new Style({
        stroke: new Stroke({
          color: '#FF0000',
          width: 2,
        }),
        fill: new Fill({
          // color: 'rgb(255, 255, 0, 0.5)',
          color: '#FFFF0080'
        }),
        text: new Text({
          font: '16px sans-serif',
          fill: new Fill({
            color: 'black',
          }),
          text: name,
        }),
      })
    }
  }),
    })
  ```

## colormap

+ `colormap` 是一个用于生成颜色渐变数组的 Node.js/NPM 包，常用于数据可视化中的颜色映射，比如热力图、分类图、三维渲染等场景

  ```javascript
  import colormap from 'colormap'

  const steps = 50
  const ramp = colormap({
    colormap: 'hot',
    nshades: steps,
  })

  function clamp(value, low, high) {
    return Math.max(low, Math.min(value, high))
  }

  function getColor(feature) {
    let heat = parseInt(feature.getProperties().heat)
    const minHeat = 30
    const maxHeat = 40
    const t = (heat - minHeat) / (maxHeat - minHeat)
    const index = Math.round(clamp(t, 0, 1) * (steps - 1))
    return ramp[index]
  }
  ```
