# 添加热力图

### 概述

+ 在 OpenLayers 中添加 热力图（Heatmap），可以使用 `ol/layer/Heatmap`，它是专门用于将大量点数据以颜色梯度的方式可视化，适用于：

  + 人流密度图
  + 气温/污染/信号强度等空间热力分布
  + 商业热区分析等场景

  ```javascript
  import { Heatmap as HeatmapLayer } from 'ol/layer'

  const vectorLayer = new HeatmapLayer({
    source: vectorSource,
    style: styleFunction,
    blur: 15,
    radius: 20,
    weight: function (feature) {
      return Math.random()
    },
  })
  ```
