# 添加动态样式

## 概述

+ 如果希望根据GeoJSON的自定义数据动态控制样式变化，可以给图层的style字段设置函数写法

  ```javascript
  const layer = L.geoJSON(hangzhou, {
    style: (feature) => {
      return {
        color: `rgba(${Math.random() * 255}, ${Math.random() * 255}, ${Math.random() * 255}, 0.9)`,
        weight: 2,
        fillOpacity: 0.5,
      }
    },
    filter: (feature) => {
      return feature.properties.name !== '富阳区'
    },
    onEachFeature: (feature, layer) => {
      layer.on('click', (e) => {
        var newLayer = e.target
        newLayer.setStyle({
          fillColor: 'red',
        })
      })
    }
  }).addTo(map)
  ```
