# 初始化地图

## 概述

+ Leaflet 是领先的开源 JavaScript 库，用于移动友好的交互式地图。它的 JS 重量仅为 42 KB，具有大多数开发人员所需的所有地图功能

+ 官方网址：</font>[https://leafletjs.com/](https://leafletjs.com/)

+ Leaflet vs OpenLayers</font>

| 对比项       | OpenLayers                                               | Leaflet                            |
| ------------ | -------------------------------------------------------- | ---------------------------------- |
| **定位**     | 功能全面、偏专业的 GIS 级地图渲染与分析框架              | 轻量化、简单易用的地图展示框架     |
| **目标用户** | 对地图有较强空间分析、投影转换、GIS 数据处理需求的开发者 | 想快速在网页上展示地图的前端开发者 |

## 初始化

+ 用Vite + Vue创建工程

  ```shell
  npm create vite@latest
  ```

+ 下载Leaflet框架

  ```shell
  npm install leaflet
  ```

+ map组件创建地图

  ```javascript
  import L from 'leaflet'

  const TDT_TOKEN = '55c0066c8dd3630394c756dfcd97add5'

  const map = L.map('map', {
    center: [30.29, 120.15],
    zoom: 6,
  })

  L.tileLayer(`http://t0.tianditu.gov.cn/vec_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=vec&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`, {
    attribution: '&copy; <a href="https://www.tianditu.gov.cn/">天地图</a>',
  }).addTo(map)

  L.tileLayer(`http://t0.tianditu.gov.cn/cva_w/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=cva&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles&TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk=${TDT_TOKEN}`).addTo(map)
  ```

+ 默认为墨卡托投影坐标系，但支持经纬度坐标

  ```javascript
  const latlng = L.Projection.SphericalMercator.unproject(L.point(13382829, 3537014))
  ```
