# chinatms插件

## 概述

+ 包含各种中国瓦片提供商的配置——天地图、百度、高德等

  ```shell
  npm install leaflet.chinatmsproviders
  ```

  ```javascript
  import 'leaflet.chinatmsproviders'

  L.tileLayer.chinaProvider('TianDiTu.Normal.Map', {
    key: TDT_TOKEN,
  }).addTo(map)
  L.tileLayer.chinaProvider('TianDiTu.Normal.Annotion', {
    key: TDT_TOKEN,
  }).addTo(map)
  ```
