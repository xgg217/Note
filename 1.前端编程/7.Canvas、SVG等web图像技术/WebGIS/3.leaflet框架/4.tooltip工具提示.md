# tooltip工具提示

## 概述

+ Leaflet 的 Tooltip 功能，就是在地图上显示一个轻量的悬浮提示框，类似浏览器里的 title 提示，但更可控、样式可定制

  ```javascript
  L.tooltip({
    permanent: true,
    direction: 'center',
  })
    .setContent('杭州市')
    .setLatLng(center)
    .addTo(map)
  ```

+ 多要素遍历Tooltip展示：

  ```javascript
  const layer = L.geoJSON(hangzhou, {
    onEachFeature: (feature, layer) => {
      const center = (feature.properties.centroid || feature.properties.center).reverse()
      const name = feature.properties.name
      L.tooltip({
        permanent: true,
        direction: 'center',
        className: 'city-label',
      })
        .setContent(name)
        .setLatLng(center)
        .addTo(map)
    },
  }).addTo(map)
  ```

  ```css
  .city-label {
    background-color: blue;
    border: 5px red solid;
    color: white;
  }
  ```
