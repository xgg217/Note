# arrowheads插件

## 概述

+ 虽然 Leaflet 旨在尽可能轻量级，并专注于一组核心功能，但扩展其功能的一种简单方法是使用第三方插件

+ leaflet-arrowheads允许用户在多段线上快速绘制箭头以进行矢量可视化

  ```shell
  npm install leaflet-arrowheads
  ```

  ```javascript
  import 'leaflet-arrowheads'

  const center = [30.29, 120.15]

  L.polyline([
    center,
    [center[0] + 0.1, center[1] + 0.1],
    [center[0] + 0.1, center[1] - 0.1],
  ], {
    color: 'blue',
  }).arrowheads().addTo(map)

  const polyline = L.polyline([
    center,
    [center[0] + 0.1, center[1] + 0.1],
    [center[0] + 0.1, center[1] - 0.1],
  ], {
    color: 'blue',
  }).arrowheads({
    size: '20px',
    frequency: 'endonly',
    color: 'red',
    fill: true,
    fillColor: 'yellow',
  }).addTo(map)
  polyline.bringToBack()
  ```
