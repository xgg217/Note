# 自定义矢量数据

## 概述

+ 除了使用Leaflet框架允许的矢量数据格式，例如：GeoJSON以外。也支持自定义矢量数据进行开发和渲染

  ```javascript
  const center = [30.29, 120.15]

  L.circle(center, {
    color: 'red',
    fillColor: '#FFFF00',
    fillOpacity: 0.5,
    radius: 5000,
  }).addTo(map)

  L.polygon([
    center,
    [center[0] + 0.1, center[1] + 0.1],
    [center[0] + 0.1, center[1] - 0.1],
  ], {
    color: 'blue',
    fillColor: '#00FF00',
    fillOpacity: 0.5,
  }).addTo(map)
  ```
