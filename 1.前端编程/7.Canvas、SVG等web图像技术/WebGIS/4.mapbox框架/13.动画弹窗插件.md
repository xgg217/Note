# 动画弹窗插件

## 概述

+ Mapbox GL JS 的动画弹出组件

  ```shell
  npm install mapbox-gl-animated-popup
  ```

  ```javascript
  import AnimatedPopup from 'mapbox-gl-animated-popup'

  map.on('click', 'layer_hz', (e) => {

    const name = e.features[0].properties.name
    const center = JSON.parse(e.features[0].properties.centroid || e.features[0].properties.center)

    new AnimatedPopup({
      openingAnimation: {
        duration: 1000,
        easing: 'easeOutElastic',
        transform: 'scale'
      },
      closingAnimation: {
        duration: 300,
        easing: 'easeInBack',
        transform: 'scale'
      }
    }).setLngLat(center).setHTML(`<div>${name}</div>`).addTo(map)

  })
  ```
