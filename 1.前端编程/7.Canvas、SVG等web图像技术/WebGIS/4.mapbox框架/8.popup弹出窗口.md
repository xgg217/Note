# popup弹出窗口

## 概述

+ 在 **Mapbox GL JS** 里，`Popup` 是用来在地图上显示信息气泡的小组件，常见用法是配合符号图层或标记点，在点击时弹出提示

  ```javascript
  map.on('click', 'layer_hz3', (e) => {

    const name = e.features[0].properties.name
    const center = JSON.parse(e.features[0].properties.centroid || e.features[0].properties.center)

    // 1. 鼠标位置弹出
    new mapboxgl.Popup()
      .setLngLat(e.lngLat)
      .setHTML(`<div>${e.features[0].properties.name}</div>`)
      .addTo(map)

    // 2. 指定中心点位置弹出
    new mapboxgl.Popup()
      .setLngLat({ lng: center[0], lat: center[1] })
      .setHTML(`<div>${name}</div>`)
      .addTo(map)

  })
  ```
