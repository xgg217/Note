# 实现地图下钻

## 概述

+ 利用 动态加载 geojson 和 setData 方法实现地图下钻功能

  ```javascript
  const hangzhou_url = 'https://geo.datav.aliyun.com/areas_v3/bound/geojson?code=330100_full'
  const hangzhou_child_url = 'https://geo.datav.aliyun.com/areas_v3/bound/geojson?code='

  map.on('load', async () => {

    const res = await fetch(hangzhou_url)
    const data = await res.json()
    map.addSource('geojson_hz', {
      type: 'geojson',
      data,
    })

    map.on('click', 'layer_hz', async (e) => {
      const adcode = e.features[0].properties.adcode
      const res = await fetch(hangzhou_child_url + adcode)
      const data = await res.json()
      map.getSource('geojson_hz').setData(data)
      map.fitBounds(bbox(data))
    })

  })
  ```
