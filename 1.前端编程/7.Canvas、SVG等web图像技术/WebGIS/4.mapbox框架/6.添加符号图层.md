# 添加符号图层

## 概述

+ Mapbox 符号图层（Symbol Layer）是 Mapbox GL JS 中用来在地图上绘制图标（icon）和文字（text）的图层类型

+ 文字

  ```javascript
  map.addLayer({
      id: 'layer_hz3',
      type: 'symbol',
      source: 'geojson_hz',
      layout: {
        'text-field': ['get', 'name'],
      },
      paint: {
        'text-color': '#FF0000',
      },
    })
  ```

+ 图标

  ```javascript
  import a from './assets/a.png'

  map.loadImage(a, (error, image) => {
    map.addImage('a', image)
    map.addLayer({
      id: 'layer_hz3',
      type: 'symbol',
      source: 'geojson_hz',
      layout: {
        'text-field': ['get', 'name'],
        'icon-image': 'a',
        'icon-size': 0.5,
      },
      paint: {
        'text-color': '#FF0000',
      },
    })
  })
  ```
