# 全栈概述与QGIS安装

## 全栈概述

+ GIS全栈指的是掌握并能独立开发从 **数据采集 → 存储管理 → 服务发布 → 前端展示与分析** 全流程的开发技能，类似于 Web 中的“前端 + 后端 + 数据库”的全栈概念

## QGIS安装

+ QGIS（Quantum GIS）是一款开源的、跨平台的桌面地理信息系统（GIS）软件，被广泛用于地理数据的可视化、编辑、分析与制图

+ 官方网址：[https://qgis.org/](https://qgis.org/)

+ 下载版本：3.40 LTR
