# PostGIS空间分析

## 概述

+ 空间分析是指对地理对象的空间关系、位置、形状、属性等进行分析处理，从而得出有价值的信息

  | **类型**   | **示例**                | **简介**                               |
  | ---------- | ----------------------- | -------------------------------------- |
  | 缓冲区分析 | 某点周围500米内的设施   | 分析一个点/线/面的周边影响区域         |
  | 叠加分析   | 土地利用+规划区重叠部分 | 将多个图层叠加，找出交集、并集、差集等 |
  | 空间查询   | 查询特定区域内的对象    | 在空间范围内筛选地理对象               |
  | 邻近分析   | 找出最近的加油站        | 分析要素之间的距离与接近性             |
  | 网络分析   | 最短路径、最优路径      | 通常用于交通导航、物流                 |
  | 统计分析   | 某区域内企业数量        | 统计某空间范围内的属性数据             |
  | 插值分析   | 土壤PH值热力图          | 将离散点数据变成连续面的预测值         |
  | 地形分析   | 坡度、坡向、可视域      | 利用DEM等栅格数据分析地形特征          |

## 分析库

+ 前端： [Turf.js](https://turfjs.org/)  （ 用户选点、生成缓冲区、画图交互  ）
+ 后端： PostGIS （ 海量数据 、 批量缓冲区 ）

  ```sql
  // sql
  SELECT * FROM city.point WHERE ST_DWithin(geom, ST_SetSRID(ST_Point(120.22, 30.26), 4326)::geography, 500)
  ```

  ```javascript
  // 前端
  const vectorSource = new VectorSource({
    url: '/geoserver/ne/ows?service=WFS&version=1.0.0&request=GetFeature&typeName=ne%3Apoints&outputFormat=application%2Fjson&maxFeatures=50&CQL_FILTER=DWITHIN(geom,POINT(120.22 30.26),500,meters)',
    format: new GeoJSON({
      dataProjection: 'EPSG:4326',
      featureProjection: 'EPSG:3857',
    }),
  })
  ```
