# 打印


## Print.js

+ 轻量 npm 库，封装浏览器打印流程，常用于 PDF/图片/HTML 的对话框打印
+ 无法绕过浏览器确认框实现生产级静默出纸

## 第三方库 web-print-pdf

+ https://www.npmjs.com/package/web-print-pdf

+ web-print-pdf 是浏览器端的 JavaScript 静默打印 SDK：通过 WebSocket 连接本机 Web 打印专家客户端，把 HTML、PDF、图片直接送到本地打印机，不弹浏览器打印对话框。终端用户需在该机器安装客户端（Windows / Linux / macOS），前端只需 npm install web-print-pdf，Vue、React、Angular 通用

+ 参考 https://webprintpdf.com/docs/printjs-comparison/?utm_source=github&utm_medium=readme&utm_campaign=tool-table
