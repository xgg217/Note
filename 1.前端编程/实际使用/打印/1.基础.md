# 基础

## 打印指令

+ ESC/POS指令，由Epson发明，是热敏小票的业内标准（看文档）
+ ZPL，有Zebra斑马发明，是面单打印的标准
+ PCL，由HP发明，是激光打印机的业内标准
+ CPCL是移动打印机指令标准
+ TSPL是台湾发明的面单打印指令
+ 还有其他很多种,TPL,EPL等等。。。

## 浏览器打印

+ `window.print()`

  + 打开系统打印对话框
  + 显示打印预览
  + 允许用户选择打印机或保存为 PDF
  + 应用打印样式（通过 @media print 定义的样式）

+ @media print 用于定义仅在打印时生效的样式规则

  ```css
  @media print {
    /* 打印时的样式 */
  }
  ```

+ 样式设置

  ```html
  <style>
    /* 使用了 .no-print 类来隐藏打印按钮： */
    @media print {
      .no-print {
        display: none;
      }

      /* 移除阴影和边框（打印时不需要视觉效果） */
      .invoice-card {
        box-shadow: none;
        border: none;
      }

      /* 隐藏导航栏 */
      nav { display: none; }

      /* 隐藏侧边栏 */
      aside { display: none; }

      /* 隐藏按钮 */
      button { display: none; }

      /* 隐藏特定类 */
      .no-print { display: none; }

      /* 避免分页时断开元素 */
      .keep-together {
        page-break-inside: avoid;
      }

      /* 在元素前强制分页 */
      .page-break-before {
        page-break-before: always;
      }

      /* 在元素后强制分页 */
      .page-break-after {
        page-break-after: always;
      }

      /* 使用黑白打印 */
      * {
        color: black !important;
        background: white !important;
      }

      /* 保留必要的颜色 */
      .important-text {
        color: black !important;
      }
    }
  </style>

  <div class="no-print">
    <button onclick="window.print()">打印按钮</button>
  </div>
  ```
