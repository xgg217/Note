# GeoServer安装

## 概述

+ GeoServer 是一个开源的 地理信息服务器，用于 发布、共享和编辑地理空间数据
+ 它基于 Java 开发，支持多种数据源（矢量、栅格、空间数据库），并且符合 OGC（开放地理空间联盟）标准，因此常用于构建 WebGIS 应用

+ Java JDK下载：[https://www.oracle.com/java](https://www.oracle.com/java/technologies/downloads/#java21)

  + Java JDK版本：17

+ GeoServer官方网址：[https://geoserver.org/](https://geoserver.org/)

  + GeoServer版本：2.27.2
