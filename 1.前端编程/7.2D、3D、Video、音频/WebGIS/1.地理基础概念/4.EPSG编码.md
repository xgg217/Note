# EPSG编码

## 概述

+ EPSG编码就是用一个编号代表一种坐标系统（包括地理、投影等），便于地图软件/库识别和统一处理坐标

+ 它可以表示：

  + 地理坐标系（如 WGS 84）
  + 投影坐标系（如 Web Mercator、UTM）
  + 地心坐标系（如 ECEF）

  | EPSG 编码 | 坐标系名称   | 类型       |
  | --------- | ------------ | ---------- |
  | 4326      | WGS 84       | 地理坐标系 |
  | 3857      | Web Mercator | 投影坐标系 |
  | 4490      | CGCS2000     | 地理坐标系 |
  | -         | GCJ-02       | 地理坐标系 |
  | -         | BD-09        | 地理坐标系 |

+ EPSG编码查询：https://epsg.io

  ```javascript
  new Map({
    target: 'map',
    layers: [
      new TileLayer({
        source: new OSM()
      })
    ],
    view: new View({
      center: [120.153576, 30.287459],   // [13375434.897310896, 3540553.792264361]
      zoom: 2,
      projection: 'EPSG:4326' // 使用wgs84坐标系，默认：EPSG:3857
    })
  })
  ```
