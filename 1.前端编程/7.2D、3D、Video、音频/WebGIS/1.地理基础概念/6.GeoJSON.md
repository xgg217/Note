# GeoJSON

## 概述

+ GeoJSON 是一种基于 JSON 的地理空间数据格式，可以是 `.json` 文件或 `.geojson` 文件，用于表示地理特征（如点、线、多边形）以及它们的属性信息
+ 它被广泛用于 WebGIS（如 OpenLayers、Leaflet、Mapbox）中进行地图数据展示和交互

+ GeoJSON编码格式：https://geojson.org/

  + feature：要素（点，线，面等）
  + properties：属性集合（可以自定义）
  + geometry：要素的图形信息（图形类别、坐标数据）

  ```json
  {
    "type": "Feature",
    "geometry": {
      "type": "Point",
      "coordinates": [125.6, 10.1]
    },
    "properties": {
      "name": "Dinagat Islands"
    }
  }
  ```

## geometry图形

+ 点

  ```js
  // type
  type: "Point"

  // coordinates（坐标）
  [119,30]
  ```

+ 多点

  ```js
  // type
  type: "MultiPoint"

  // coordinates（坐标）
  [
    [119, 30],  [120, 31], ...
  ]
  ```

+ 线

  ```js
  // type
  type: "LineString"

  // coordinates（坐标）
  [
    [119, 30],  [120, 31], ...
  ]
  ```

+ 多线

  ```js
  // type
  type: "MultiLineString"

  // coordinates（坐标）
  [
    [
      [119, 30],  [120, 31], ...
    ],
    [
      [121, 32],  [122, 33], ...
    ]
  ]
  ```

+ 面

  ```js
  // type
  type: "Polygon"

  // coordinates（坐标）
  [
    [
      [119, 30],  [120, 31], ...
    ]
  ]
  ```

+ 多面

  ```js
  // type
  type: "MultiPolygon"

  // coordinates（坐标）
  [
    [
      [119, 30],  [120, 31], ...
    ],
    [
      [121, 32],  [122, 33], ...
    ]
  ]
  ```

## 同时表示多个要素

+ GeoJSON 有时候会一次性表示多个要素：

  ```json
  {
    "type": "FeatureCollection",
    "features": [
      {
        "type": "Feature",
        "properties": { "name": "宁波市" },
        "geometry": {
          "type": "Point",
          "coordinates": [120.3422342, 29.23423]
        }
      },
      {
        "type": "Feature",
        "properties": { "name": "杭州市" },
        "geometry": {
          "type": "Point",
          "coordinates": [120.3422342, 29.23423]
        }
      }
    ]
  }
  ```
