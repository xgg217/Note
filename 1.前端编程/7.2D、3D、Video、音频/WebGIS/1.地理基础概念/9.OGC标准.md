# OGC标准

## 概述

+ [OGC](https://www.ogc.org/)(Open Geospatial Consortium) 开放地理空间信息联盟。它是一个国际组织，专门负责制定 **GIS 领域的开放标准**，以便不同厂商、平台之间的数据、服务可以互通

## OGC 标准的主要目标

+ 让地图服务和空间数据能够跨平台、跨语言互通

+ 栅格数据：WMS服务、WMTS服务
+ 矢量数据：WFS服务

  | **标准名称**    | **英文缩写**                                       | **说明**                                                    |
  | --------------- | -------------------------------------------------- | ----------------------------------------------------------- |
  | WMS             | Web Map Service                                    | 地图图像服务：通过 HTTP 请求地图图像（如 PNG、JPEG）        |
  | WFS             | Web Feature Service                                | 矢量数据服务：支持获取和操作地理要素数据（如 GeoJSON、GML） |
  | WCS             | Web Coverage Service                               | 栅格数据服务：返回遥感影像、DEM 等覆盖数据                  |
  | CSW             | Catalogue Service for the Web                      | 地理元数据服务：搜索和访问空间数据目录（如地图、数据集）    |
  | WMTS            | Web Map Tile Service                               | 地图切片服务：按瓦片方式提供地图数据，适用于高效加载        |
  | GML             | Geography Markup Language                          | 地理标记语言：XML格式，用于编码地理空间要素和属性           |
  | KML             | Keyhole Markup Language                            | Google开发，用于地图展示和共享位置数据（OGC已采纳）         |
  | SFS             | Simple Feature Specification                       | 简单要素规范：定义几何类型如点、线、面及其操作规则          |
  | SENSOR ML / SOS | Sensor Model Language / Sensor Observation Service | 传感器数据建模和访问服务，用于物联网、环境监测等            |
  | GeoPackage      | GPKG                                               | 一种基于 SQLite 的地理空间数据容器，适用于移动端            |


  ```powershell
  # WMS请求示例
  http://yourserver.com/geoserver/ows?service=WMS&version=1.3.0&request=GetMap&layers=city:roads&styles=&bbox=...&width=800&height=600&format=image/png
  ```

## 瓦片

+ WMTS网络地图瓦片服务，就是把地图分成许多等份，每一份通常是256x256像素大小的图片，提供浏览器加载性能。

+ 图片切割完之后再对图片进行编号，编号的规则是这样的：首先要确定当前的层级（也就是当前的比例尺）我们简称为z， 行号我们记作x，列号记作y。因此根据三个数字xyz就能够获取唯一一张图片。

+ 瓦片示例：[https://docs.maptiler.com/google-maps-coordinates-tile-bounds-projection/](https://docs.maptiler.com/google-maps-coordinates-tile-bounds-projection/)
