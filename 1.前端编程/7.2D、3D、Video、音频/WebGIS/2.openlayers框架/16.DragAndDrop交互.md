# DragAndDrop交互

## 概述

+ 允许用户 **拖拽文件**（如 `.geojson`, `.kml`, `.gpx`, `.igc`）到地图上并自动加载为矢量图层

  ```javascript
  import { DragAndDrop } from 'ol/interaction'

  map.addInteraction(
    new DragAndDrop({
      source: vectorSource,
      formatConstructors: [GeoJSON],
    })
  )
  vectorSource.on('addfeature', () => {
    const newExtent = vectorSource.getExtent()
    map.getView().fit(newExtent)
  })
  ```
