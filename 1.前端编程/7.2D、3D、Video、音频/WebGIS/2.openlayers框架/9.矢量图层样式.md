# 矢量图层样式

## 概述

+ OpenLayers框架可以通过style组件给矢量数据添加样式

  ```javascript
  import { Style, Fill, Stroke, Text } from 'ol/style'

  const vectorLayer = new VectorLayer({
    source: vectorSource,
    style: new Style({
      stroke: new Stroke({
        color: '#FF0000',
        width: 2,
      }),
      fill: new Fill({
        // color: 'rgb(255, 255, 0, 0.5)',
        color: '#FFFF0080'
      }),
      text: new Text({
        font: '16px sans-serif',
        fill: new Fill({
          color: 'black',
        }),
        text: '杭州',
      }),
    }),
  })
  ```
