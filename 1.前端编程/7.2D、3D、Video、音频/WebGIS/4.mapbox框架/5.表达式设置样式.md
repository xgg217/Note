# 表达式设置样式

### 概述

+ 在 Mapbox GL JS 中，您可以将任何布局属性、绘画属性或过滤器的值指定为表达式。表达式定义如何使用逻辑、数学、字符串或颜色运算组合一个或多个要素属性值或当前缩放级别，以生成适当的样式属性值或过滤器决策

  ```javascript
  paint: {
    'fill-color': [
      'match',
      ['get', 'name'],
      '临安区',
      'green',
      '富阳区',
      'pink',
      '建德市',
      'skyblue',
      'yellow',
    ],
    'fill-opacity': 0.5,
  }
  ```

  ```javascript
  paint: {
    'fill-color': [
      'step',
      ['number', ['coalesce', ['get', 'adcode']]],
      'yellow',
      330110,
      'skyblue',
      330120,
      'pink'
    ],
    'fill-opacity': 0.5,
  }
  ```
