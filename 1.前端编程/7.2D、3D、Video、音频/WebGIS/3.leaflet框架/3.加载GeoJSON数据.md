# 加载GeoJSON数据

## 概述

+ 支持GeoJSON数据添加到地图

  ```javascript
  import hangzhou from './assets/hangzhou.json'

  const layer = L.geoJSON(hangzhou, {
    style: {
      color: 'red',
      weight: 2,
      fillColor: 'yellow',
      fillOpacity: 0.5,
    },
  }).addTo(map)

  map.fitBounds(layer.getBounds())
  ```

+ 支持远程GeoJSON文件加载

  ```javascript
  const response = await fetch('https://geo.datav.aliyun.com/areas_v3/bound/geojson?code=330100_full')
  const geojson = await response.json()

  L.geoJSON(geojson)
  ```
