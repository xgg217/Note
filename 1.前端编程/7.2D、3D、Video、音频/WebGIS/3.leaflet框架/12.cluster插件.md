# cluster插件

## 概述

+ 美观、复杂、高性能的标记聚类解决方案，具有流畅的动画和许多出色的功能

  ```shell
  npm i leaflet.markercluster
  ```

  ```javascript
  import 'leaflet.markercluster'
  import 'leaflet.markercluster/dist/MarkerCluster.css'
  import 'leaflet.markercluster/dist/MarkerCluster.Default.css'
  import point from './randomData.js'
  import icon from './assets/icon.png'

  const markers = []
  point.forEach((f) => {
    const largeIcon = L.icon({
      iconUrl: icon,
      iconSize: [40, 40],
    })
    const marker = L.marker([f.lat, f.lng], {
      icon: largeIcon,
    })
    markers.push(marker)
  })

  const markerClusterLayer = L.markerClusterGroup({
    showCoverageOnHover: false,
    zoomToBoundsOnClick: true,
    maxClusterRadius: 80,
  }).addTo(map)
  markerClusterLayer.addLayers(markers)
  map.fitBounds(markerClusterLayer.getBounds())
  ```
