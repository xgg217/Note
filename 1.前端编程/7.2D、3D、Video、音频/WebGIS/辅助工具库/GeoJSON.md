# GeoJSON

## 作用

+ GeoJSON 是一种基于 JSON 的地理空间数据格式，可以是 `.json` 文件或 `.geojson` 文件，用于表示地理特征（如点、线、多边形）以及它们的属性信息

+ GeoJSON编码格式：https://geojson.org/

+ 自定义绘制geojson数据：https://geojson.io/
+ shape和geojson等数据进行转换：https://mapshaper.org/
+ 获取中国相关的geojson数据：https://datav.aliyun.com/portal/school/atlas/area_selector
