# 路径规划 2.0

### 概述

+ 路线规划接口2.0是一类 Web API 接口服务，以 HTTP/HTTPS 形式提供了多种路线规划服务
+ 支持驾车、公交、步行、骑行、电动车路线规划

  + 驾车路线规划
  + 步行路线规划
  + 骑行路线规划
  + 电动车路线规划
  + 公交车路线规划

## 驾车路线规划

+ 驾车路线规划

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const origin = '116.310003,39.991957'
  const destination = '116.434446,39.90816'
  const url = `https://restapi.amap.com/v5/direction/driving?key=${GD_TOKEN}&origin=${origin}&destination=${destination}`

  fetch(url)
    .then(response => response.json())
    .then(data => {
      console.log('Geocode data:', data)
    })
    .catch(error => {
      console.error('Fetch error:', error)
    })
  ```
