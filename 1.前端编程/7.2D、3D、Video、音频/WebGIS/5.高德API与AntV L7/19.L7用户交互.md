# 19. L7用户交互

## 概述

+ 地理可视化除了数据展示，还需要用户交互，用户交互一般分为两种

  + 图层交互
  + 数据交互

  ```javascript
  polyLayer.active(true)
  polyLayer.active({
    color: '#FF0000',
  })

  polyLayer.select(true)
  polyLayer.select({
    color: '#00FF00',
  })
  ```

  ```javascript
  polyLayer.on('click', (e) => {
    console.log('click', e.feature.properties)
  })
  ```

  ```javascript
  const handleClick = () => {
    polyLayer.setActive(6)
    polyLayer.setSelect(6)
  }
  ```
