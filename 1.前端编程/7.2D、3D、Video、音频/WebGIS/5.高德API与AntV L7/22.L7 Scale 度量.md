# L7 Scale 度量

## 概述

+ Scale 度量是用于将地图数据值（数字、日期、类别等数据）转成视觉变量（颜色、大小、形状）
+ Scale 是数据可视化的基本元素，因为它们决定了数据视觉编码的方式。L7 目前支持连续、离散、枚举类型等常用的 Scale

  + Domain: 地图数据值的定义区间
  + Range：视觉值的区间定义

  ```javascript
  // cat枚举
  .color('name', ['red', 'blue'])

  // linear线性
  .color('temp', ['red', 'blue'])

  // quantize等间距
  .scale('temp', {
    type: 'quantize',
    domain: [10, 25],
  })
  .color('temp', ['red', 'blue'])
  ```
