# 调用工具插件

## 概述

+ 还有一类 工具插件 ，这些插件不是业务服务，而是提供地图功能增强或用户交互体验的小工具

+ 比如：绘制、距离面积测量等

  ```vue
  <script setup>
    const handleDraw = () => {
      mouseTool.polyline({
        strokeColor: "#3366FF",
        strokeOpacity: 1,
        strokeWeight: 6,
        strokeStyle: "solid",
      })

      mouseTool.polygon({
        strokeColor: "#FF33FF",
        strokeOpacity: 1,
        strokeWeight: 6,
        strokeOpacity: 0.2,
        fillColor: '#1791fc',
        fillOpacity: 0.4,
        strokeStyle: "solid",
      })
    }

    AMap.plugin("AMap.MouseTool", function () {
      mouseTool = new AMap.MouseTool(map)
    })
  </script>
  <template>
    <div id="map"></div>
    <el-button id="btn" @click="handleDraw">绘制</el-button>
  </template>
  <style scoped>
  #map {
    position: absolute;
    inset: 0;
  }

  #btn {
    position: absolute;
    top: 10px;
    left: 10px;
  }
  </style>
  ```

    mouseTool = new AMap.MouseTool(map)

      console.log(e.obj) // e.obj 即为绘制出来的覆盖物对象
