# L7中使用高德插件

## 概述

+ 当L7框架选择GaodeMap作为底图的时候，是可以直接使用高德所提供的插件

  ```javascript
  window._AMapSecurityConfig = {
    securityJsCode: '41666af21c674a347f2f5ccb2376a9be',
  }
  const GD_TOKEN = 'e80ed49a1861eea77f72f826ec23f8af'

  const scene = new Scene({
    id: 'map',
    map: new GaodeMap({
      center: [120.15, 30.29],
      zoom: 5,
      token: GD_TOKEN,
      plugin: ['AMap.Scale', 'AMap.ToolBar', 'AMap.Driving'],
    }),
  })

  scene.on('loaded', () => {
    scene.map.addControl(new AMap.ToolBar())
    scene.map.addControl(new AMap.Scale())

    const points = [
      { keyword: '北京市地震局（公交站）', city: '北京' },
      { keyword: '亦庄文化园（地铁站）', city: '北京' }
    ]
    const driving = new AMap.Driving({
      map: scene.map,
      panel: "my-panel",
    })
    driving.search(points, function (status, result) {
      if (status === "complete") {
        console.log("驾车导航信息：" + result)
      } else {
        console.log("获取驾车数据失败：" + result)
      }
    })
  })
  ```
