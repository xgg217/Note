# 搜索POI 2.0

## 概述

+ 地点搜索服务2.0是一类 Web API 接口服务；服务提供多种场景的地点搜索能力，包括关键字搜索、周边搜索、多边形区域搜索、ID 搜索

  + 关键字搜索
  + 周边搜索
  + 多边形区域搜索
  + ID搜索

  ```javascript
  const GD_TOKEN = 'fd7a0e4975078b5d697d478286ce46a8'
  const types = 'KTV'
  const region = '北京市'
  const url = `https://restapi.amap.com/v5/place/text?key=${GD_TOKEN}&types=${types}&region=${region}`

  fetch(url)
    .then(response => response.json())
    .then(data => {
      console.log('Geocode data:', data)
    })
    .catch(error => {
      console.error('Fetch error:', error)
    })
  ```
